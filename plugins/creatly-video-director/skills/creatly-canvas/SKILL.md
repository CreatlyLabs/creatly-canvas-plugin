# Creatly 画布操作

把用户提供的内容和已确认的执行要求落实到 Creatly 画布。先识别目标项目、节点及操作范围，保留已有素材和用户修改。已知 ID 时直接读取目标，不另建重复项目。

## 执行原则

- 使用插件已连接的 `yuanji` MCP；实时工具定义和模型目录决定可用能力，不用文档清单替代连接验证。
- 默认将人物、角色、场景、物品或道具等创作资产做成普通图片节点：按任务写入提示词和真实参考素材，并在用户授权范围内生成。普通图片任务不调用主体查询、创建、资产计划或绑定工具；只有用户明确要求“创建主体”或“添加到主体库”等正式主体建档时，才调用 `createSubject` 等主体创建工具；“创建人物/物品/设定图”本身不代表创建主体。用户明确要求使用已有主体时，可读取或引用已有主体，但不因此新建主体。
- 每次实际执行画布任务，确定目标项目后默认在右侧打开画布；先检查当前预览，同一画布已打开就复用，用户关闭后在下次触发时重新打开。不把“以前打开过”当作当前仍打开，不在后台轮询中重复打开。按[画布预览](references/canvas-preview.md)使用宿主实际能力；用户明确不打开时从其要求。
- 项目、节点、主体、文件和任务 ID 原样使用真实回执；不互换、不转成 JavaScript Number、不从画布 URL 推算。
- 先读简要目录，再按 ID 读取必要字段。同一版本、同一范围的回执复用，不为修改少量节点遍历全画布详情。
- 参数按实时 Schema 平铺传递。版本校验、删除摘要、源文件和幂等键等字段取自当前回执；冲突时先重读。
- 保留用户的正文、提示词、素材顺序和已有配置；只有任务明确要求时才修改。文本直接输入不需要调用生成。
- 新建节点和分组默认按[二维紧凑排版](references/layout.md)利用空间，让实际占用范围的宽高尽量接近；按节点显示尺寸选列数并换行，组内与组间都适用，不沿单一方向无限延伸。新增内容优先填空位或扩展整体较短的一边；保留用户指定布局、内容与连线。
- 付费生成遵守用户已给出的范围和预算授权，报价与配置一致，传入实际预算上限；没有授权的新增支出先确认。
- 超时先查询原操作或任务，不换幂等键重复提交。生成成功、文件挂载成功和内容质量通过是不同状态。
- 完成节点操作或查询生成结果后，图片、视频、音频等节点统一用 Markdown 富文本交付：节点名称作为可点击链接，旁边注明类型和真实状态。图片节点也直接用图片名称链接到对应画布节点，不只返回任务 ID、图片文件地址或代码形式的 URL；不贴裸网址或整份 JSON。多个结果用短列表或表格，具体格式、地址来源与旧版本回退见[节点交付与定位链接](references/reading.md#给用户定位链接)。
- 同时说明实际输出、任务状态及待处理问题；定位链接不是生成成功的证据，未执行的计划不描述为已同步。

用户只要求画布操作时，直接执行该范围。人物横版四视图使用本技能提供的模板；其他编剧、选角、摄影、镜头编排和内部创作方法不随本技能提供。使用用户已有内容或其另外提供的创作方案，不要求安装私有技能才能完成基础操作。
