# 元极画布操作

把用户提供的内容和已确认的执行要求落实到元极画布。先识别目标项目、节点及操作范围，保留已有素材和用户修改。已知 ID 时直接读取目标，不另建重复项目。

## 执行原则

- 使用插件已连接的 `yuanji` MCP；实时工具定义和模型目录决定可用能力，不用文档清单替代连接验证。
- 项目、节点、主体、文件和任务 ID 原样使用真实回执；不互换、不转成 JavaScript Number、不从画布 URL 推算。
- 先读简要目录，再按 ID 读取必要字段。同一版本、同一范围的回执复用，不为修改少量节点遍历全画布详情。
- 参数按实时 Schema 平铺传递。版本校验、删除摘要、源文件和幂等键等字段取自当前回执；冲突时先重读。
- 保留用户的正文、提示词、素材顺序和已有配置；只有任务明确要求时才修改。文本直接输入不需要调用生成。
- 付费生成遵守用户已给出的范围和预算授权，报价与配置一致，传入实际预算上限；没有授权的新增支出先确认。
- 超时先查询原操作或任务，不换幂等键重复提交。生成成功、文件挂载成功和内容质量通过是不同状态。
- 完成节点操作或查询生成结果后，用 Markdown 富文本交付：节点名称作为可点击链接，旁边注明类型和真实状态；不贴裸网址、代码形式的长链接或整份 JSON。多个结果用短列表或表格，具体格式、地址来源与旧版本回退见[节点交付与定位链接](references/reading.md#给用户定位链接)。
- 同时说明实际输出、任务状态及待处理问题；定位链接不是生成成功的证据，未执行的计划不描述为已同步。

用户只要求画布操作时，直接执行该范围。编剧、选角、摄影、镜头编排、提示词模板和创作质量规则不随本技能提供；使用用户已有内容或其另外提供的创作方案，不要求安装私有技能才能完成基础操作。
