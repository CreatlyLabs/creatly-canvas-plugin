# 媒体生成、能力与费用

本文件规定核验和执行方式，不把历史平台上限当成当前事实。实际生成前同时读 [工具适配](tool-adaptation.md)。

## 模型偏好与有效能力

Creatly / 元极的图片默认：写实分镜、角色和场景的定稿用 **Nano Banana 2**（model=gemini-3.1-flash-image-preview，modelConfigId=nano_banana_2，provider=image_nano_banana，function=nano_banana，16:9、1K）；需要快速出草稿时可用 **Sunburst，标准画质**（model=gpt-image-2.5-sunburst，function=gpt25_sunburst，配置ID=image_gpt25_sunburst，quality=medium）。用户当前指定覆盖默认。以上映射记录于 2026-09 的元极平台，提交前以 `listGenerationModels` 实时目录和接口字段为准，不向不接受 function 的接口硬传参数；不传 `quality: null`。质量档位与分辨率独立，不把标准画质误写成 2K 或 4K。映射不是底层供应商身份声明。

默认模型不可用时说明限制，不自动换成其他付费模型；在其他平台也不假设同名模型存在。偏好不提高数量、质量、费用，也不追溯重生成旧图。

视频默认 **Seedance 2.5、480p、开启音频**。通过实时 `listGenerationModels(scene="video", detail="compact")` 定位模型，再带目标 modelIds 精读 full 解析可用参数；新建视频节点时显式传入 `generationParams.resolution="480p"` 和 `generationParams.bgm=true`，不依赖网站或模型的隐式默认值。用户明确指定的模型、分辨率或静音要求优先；默认组合不可用时说明缺口，不自动升级分辨率或换用其他付费模型。默认值只用于本次新建视频或用户要求调整的节点，不覆盖既有节点的已确认配置，也不触发重生成。`bgm` 是音频总开关，不是配乐开关；不要背景音乐时保留音频开启，并在提示词写「无背景音乐」。读取真实工具 schema、模型目录，必要时查官方资料，记录：实际模型/渠道、时长档位、提示词计数口径、引用类型/数量、画幅、原生分辨率、音频能力、段内多镜、延伸、来源和日期。

需要4K时先查原生能力，区分原生生成和后期放大；不能只凭版本名自动切到某模型。未核验能力时交付待执行设计；不得据旧的“4–30秒”“4500字”等值提交超限请求。

## 本批预算

在项目状态中记录批次、范围、模型、张/段数、报价、上限、已确认支出、处理中预留、退款状态及授权依据。预算可用余额＝上限－已确认支出－未结算任务预留；未知计费/退款不视为免费或已返还。

一次批准可覆盖本批多个节点，不需要每节点再次确认。用户指定四段就不能凭剩余预算增加第五段；用户授权在总预算内自主迭代时按该范围记录。每次提交前复核累计费用和待扣费请求，工具支持上限则使用。超预算、改模型、扩数量、未授权重试需补充对话授权。

失败或超时先查原任务/账单；没有已失败证据不重复提交。准备、估价、批准、任务回执、实际扣费分别记录，不能把估价当实际消费。

## 资产准备

- **角色**：先按 [选角](casting.md) 定演员，再整理需要的服装、角度和剧情状态。头肩+全身可以作身份板，不强制首轮就生成完整套图。实际镜头只要一个视图就不机械凑齐六图。多造型沿用已确认身份。
- **场景**：固定同一空间地理与光向，按机位需要补反向视图。场景图服务可拍空间，静态分镜另定裁切和人物位置。
- **道具**：关键物单独定形，明确握持、归属、数量与状态。受损版按剧情需要补，不为所有状态预生成。
- **声音**：需要音色参考或定长对白时先准备可用音频、文字、用途和授权。按实际音频工具能力执行，不预设特定音频模型存在。被视频引用的音频须先验证，剩余 BGM/VO 可后做。

## 提交与验收

先设计摄影镜头/时长，再按 [生成单元](editing-and-generation-units.md) 打包请求。一个请求可含多个短镜；连续长镜也可跨请求续接，但只在能力可行且符合用户格式要求时执行。

每个请求核对：真实引用与顺序、单镜/多镜契约、完整提示词计数、参数、前置音频、当批预算。生成后实际看图/看片/听音，检查身份、光材、空间、动作、对白和接头。仅查看缩略图不能证明完整运动/声音合格；视觉结果与挂载结果分别验收。

同一问题经一次有针对性的修正仍失败时，保留版本、实际错误与已尝试方法，停止相同提交。改变方案、模型或新增付费次数前先核对用户授权；不无限抽卡。

## 延伸

仅在当前工具确认支持时使用。明确“源末帧之后”或“源首帧之前”，再映射实际方向字段，不凭英文 forward/backward 猜测。

保留源片段，记录源目标、原视频/边界状态、延伸请求、新输出。提示词只写新增动作及衔接状态；机位、光向、手别、动作相位和速度须接续。返回可能是增量或完整延长视频，实际检查后决定入出点，避免重复拼接。需要换机位、改人物或重构画面时属于新镜头设计，不默认靠延伸解决。
