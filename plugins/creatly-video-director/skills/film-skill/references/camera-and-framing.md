# 机位与构图细拆：画面，不是剧情复述

用于学习参考作品的摄影，或把“过肩、从脚拍到人、新人物出场”写成可生成、可验收的分镜。案例来源为 [Neowow《万物生》《万物生：问心》](https://neodomain.cn/neo-tv) 的只读创作画布和成片抽样；不是完整拉片，也不是作者官方教程。

内容：取样与比例口径 → 来源构图卡 → 原创可执行模板 → 验收。

## 1. 看什么、怎样记录

不要把“此人发现危险”当摄影分析。记录“前景右侧背肩留在画内、远处目标出现在左侧负空间、焦点何时转移”。同一事件可以用完全不同的画面拍。

对一个运动镜头至少辨认起幅、重要中间构图、落幅。单张截图只能证明一个瞬间，不能证明上摇、升降、环绕、变焦或切镜。拖动播放条后确认画面与时间已经更新，缓冲时不能拿旧帧配新时间。没有完整看到运动就标记待核验。

每张构图卡按需填：

| 维度 | 必须能回答的问题 |
| --- | --- |
| 景别与裁切 | 头顶是否切掉？底边在胸、腰、膝还是脚下？说“半身”仍需说明裁切处 |
| 机位 | 在谁前/后、哪一侧，俯仰角与高度怎样？来源没写数值就不用猜测成精确镜头参数 |
| 人物比例 | 可见人物外接框宽/W、高/H；是全身还是被裁切后的部分？多人分别记，不用一个“占屏70%”混写 |
| 布局 | 人物中心位置、眼线高度、头顶留白、视线和运动方向的空位 |
| 前景 | 哪个肩、背头、门框或物体占哪边？遮的是底角还是整条边？是否挡住对面脸/手/道具 |
| 景深 | 前、中、后景各是谁，谁清晰；是否移焦，在哪个可见动作后移焦 |
| 人物调度 | 最初在画内还是画外，从哪条边或哪个门口进入，到哪里停，露哪些部位 |
| 摄影机运动 | 固定/转动/平移/升降/变焦分别是什么；相对人物的距离和方位是否变化 |
| 构图变化 | 起幅→中间→落幅，每个阶段新增或退出了什么，比例怎样变化 |

比例口径：只以有效影像的宽 W、高 H 为分母，不包括浏览器、字幕栏、播放器控件或上下黑边。外接框比例不是人物不规则轮廓的实际面积。目测给范围，不伪装成像素分割测量。

三个证据标签要保留：**P：节点提示词明确值；V：成片画面目测；D：新镜头设计建议。** P 是作者意图，不自动等于生成结果。D 不能说成该作者原来的参数。

## 2. 来源构图卡

### A. 极低机位只拍腿：别误记为“脚到脸”

P，2026-09-13 新读取，《问心》开场分组中脚部缩略图视频节点；可辨认节点标识 `video-1779305150746-udwca57zv`。界面显示 6 秒、21:9，正文要求 5 秒连续镜头、16:9；这些不一致不能照抄到新任务。

- 摄影机距沙面约 **30–40 cm**，朝走来的人略微仰拍。
- 持续倒退，与人物前进速度相配，人物在纵深中的位置保持稳定；手持起伏叠加在后退路径上。
- 人物位于**画面左三分之一附近**，可见腿部约占**画宽四分之一**。
- 上边界裁在**大腿中段**，只见该处以下，脸与上身全程不出现。
- 沙地约占画高 **2/3**，天空约 **1/3**；右侧大片空沙地形成不对称构图。
- 每一步足底离沙、落足、沙粒掉落和裙摆延迟摆动提供运动层次；身体节奏与镜头晃动分开描述。

迁移：先写“可见范围”和“同步跟随”，再写质感。这里**没有从脚向上摇到脸**，不能因首帧是腿就声称已学到原作的上摇镜头。原文有节拍绝对一致的强调；新片若要自然步态，应允许微小差异，不必照抄机械节拍。

### B. 正面脸 → 右肩过肩 → 下身：连续运镜有落点

P，《问心》行走独白视频节点，界面 15 秒。正文描述从脸部高度开始的顺时针、逐渐下降的环绕，同时跟随人物前进。

- 起幅：正面面部近景，人物居中，先停留约 3 秒。
- 中段：转向人物右侧，再形成**从她右肩后看出去**的过肩画面。身体右肩/后脑落在**屏幕左前景**，另一个人在**中远景偏右**。
- 后段：下降到裙摆、腿与赤足的可见范围。

关键：身体的“右肩”和屏幕的“右边”不是同一概念。写清摄影机在人物哪一侧，也写清肩膀最终落在画面哪一侧。该节点没有给肩膀占屏百分比；不能补一个数再冒称来源值。正文的整圈要求与数个落点需要实际视频核对，不能仅凭文字保证输出完成了 360°。

### C. 起身入画 → 环绕 → 侧后过肩：人动与机动分开

P，《问心》部落段视频节点，界面 15 秒；本次重新读到完整提示词。

- 开始是近地低角度、倾斜中近景；主体**还不在画面里**，背景有人群。
- 人物由趴跪站起，**从画面下边缘进入**，最后被裁成上半身与脸。
- 摄影机沿左→右圆弧绕行；人物自身右→左转身。两种旋转不是一句“环绕人物”能替代的。
- 落幅转成侧后过肩：前景侧背和部分侧脸，远方地平线保留开口；摄影机先稳定，再让远处对象出现。

迁移：用“尚未入画→头肩越过底边→半身落位”定义出现过程。**人物站起来导致脸进入画面，不等于摄影机从脚上摇。** 来源的近半身与极小人物尺度描述存在张力；改编时须指定景别是否继续拉远，不能同时要求人物贴近占满与小如微点。

### D. 新人物先露腿：固定镜头里的深度入场

P，《万物生》化妆间视频节点，之前已读取；未核验其与另一个化妆间截帧一一对应。

- 摄影机离地约 **30–40 cm**，约向下 **15°**，固定不动。
- 前景：趴低的人物位于**中偏左、下方区域**，脸、颈肩、肘和手是主要可见部分，保持清晰。
- 中景：另一个人物只露**膝至腰**，位于前景人物身后，朝屏幕左侧，较虚。
- 后景：门在**右上**，只见门的下方约 **1/3**；开始无人，门口最虚。
- 新人物从后景门口进入，只露下半身，向中景移动，停在原中景人物的右侧。前景人物仍是焦点，没有因新人出现自动移焦到她脸上。

迁移：新人不必立刻“全身正面站中间”。先让服装轮廓、腿、手或投影进入预留区域；是否随后给脸由需要决定。门的下方 1/3 是**门本身可见比例**，不是它占画高 1/3。

### E. 门口斜侧机位：入画方向给后续动作留路

P，《问心》帐篷出门节点。

- 第一镜在帐篷前方约 **45°斜侧**，门口在**画面右边**；人物掀帘出来，村落纵深留在另一侧，摄影机缓推。
- 下一镜换到前左侧面部近景，并非简单把原画面中心放大。
- 冲出画面时摄影机滞后半拍，容许短暂空画；再切后方跟随，人群可穿过近前景遮挡。

迁移：出门前就在构图中留下移动通道。入口、停点、离开方向、摄影机何时跟上分别写，避免“人物出现后乱走、镜头追丢”。

### F. 巨人市集：靠同框比例，不靠形容词

P，《问心》市集横移节点。

- 机位在普通成人肩高，向左横移；巨人在中景中心，纵向接近占满画高。
- 普通人可见高度约为画面的**下方 1/3**，其头部到巨人腰附近，形成同框比例参照。
- 前景织物先遮满再向下撤开；末端近处背披风的人右→左经过，可逐渐盖住画面。
- 后景人群也右→左走，但速度比摄影机横移更快；人物移动、镜头移动和视差不能只写同一个“往左”。

这是夸张尺度的特定设计，不是要求每个主角满屏。若要复制比例，需要同时锁住两类人物的景深位置，不能仅让普通人远得多来冒充身高差。

### G. 极远景双人：主体很小也能有清楚构图

P，《问心》沙丘双人视频节点。

- 双人及间隔合计约占**画宽 1/20（5%）**，放在左三分之一附近。
- 地平线在下三分线，天空约占 **2/3 画高**；右边约 **2/3** 保留为空旷空间。
- 先静止约 2 秒，再发生横向/向深处的移动；起幅的负空间是运动将进入的地方。

不要把“合计宽 5%”写成“两人高度 5%”。这种小主体远景也不能用普通中景的人物细表情来验收。

### H. 顶拍人物造型：整体轮廓控制占比

P，《问心》双人构成数字 2 的静帧节点。

- 90°正顶拍；组合轮廓约 **35–40% 画宽、60–70% 画高**，水平居中，两边沙地留白。
- 这里锁的是两个人的**组合外轮廓**，不是每个人各占该比例，也不是独立人物身高。
- 静态设计需把接触位置、姿态、拖痕方向写明，不把一段先后动作塞进单幅画面。

### I. 成片面具头部近景：提示词比例要与实际画面区分

V，本次查看成片播放器 **02:44 / 11:41** 的暂停画面。有效影像约为截图 x=82–1257、y=174–701；不计下面字幕和播放器。

- 前景面具与头发的可见外接范围目测约为 **50–55% 画宽、90–100% 画高**；顶部略裁切，底部近地面。
- 主体在左中区域，右侧保留约四成宽的背景空间，背景显著更虚。
- 这只是该暂停帧的目测，不是精确测量、摄影参数或整段运动说明；头部满高不等于全身满高。

## 3. 原创镜头模板：把学到的控制方法用于新片

以下全部为 **D（设计建议）**，比例只是起点，可按画幅、角色和实际生成结果调整，不声称是原作数值。只选本镜必要的几个量，别把百分比堆满提示词。

### 过肩对视：把遮挡和被看者分开锁

16:9 例：摄影机在 A 右肩后。A 的后脑与右肩占屏幕左缘约 20–25% 的宽度，轮廓柔焦，不遮 B 的脸与持剑手；B 在中景偏右，中心约 x=65%W，可见腰以上，高约 70–80%H，眼线约 y=33–40%H。镜头固定，B 只轻微转头看向 A。焦点留在 B，不因 A 肩膀移动跳焦。两人视线留在中央开口，不贴画边。

验收：A 肩膀出现但没抢主体；B 不是挤在边缘；看得到视线指向。反打应重新明确另一侧肩与屏幕位置，并保持同一条对话轴线，不能自动镜像衣服或武器。

### 脸部近景与反应插镜：让情绪接住台词

漫剧可用脸部特写和听者反应承接情绪，沿用已确认的光材方向。按本项目需求取舍，不设固定特写比例。

- **近景与特写要写清裁切**：胸口以上近景还能读肩部动作；脸部特写以额头至下巴和少量颈肩为主，眉眼、嘴角能清楚辨认；眼部或嘴部大特写只用于具体线索，不默认每次都切。不要只写“特写”，输出却仍是膝上双人镜。
- **明确谁在看谁**：视线留白朝对手方向，保持对话轴线、眼线高度和身体朝向；可留少量虚化肩缘作为空间参照。角色不是对着观众展示正脸。
- **切在情绪触发点**：说话者的重音、听者意识到话是对自己说、笑容收住、眼神躲开、想辩解却咽回去，才是切近的理由。不要全句说完、全身动作做完、停稳之后才给反应。
- **声音跨镜，表演接续**：说话者声音继续时，可切到听者的眼神变化；听者不跟着说话者台词张嘴。下一位开口也可提前接入画外声，再切其近景。环境声连续，不每次切镜重置。
- **景别搭配**：按需要用关系中景交代距离，面部近景突出一句话或一个判断，短反应特写表现后果，再回双人/行动镜推进。不机械一人一句正反打，不规定特写数量、固定秒数或占比；若紧凑特写已清楚表达双方关系，也不强制补大全景。
- **近景中仍有行动状态**：人物迈步、转身、呼吸和视线承接前镜，不因切到脸就站桩。重心变化、脚步声或背景视差可以延续画外身体动作，但关键接触/道具易手不能全部藏在脸部特写之外。
- **光材一致且克制**：换机位继承场景光源，不把“每张脸左边亮”当连续性；近景尤其检查五官漂移、磨皮、夸张眼白、嘴唇和皮肤闪烁。脸部情绪清晰，不等于浓妆、夸张变脸或强行加毛孔。

原创设计用途例（尚非提交提示词）：公子质问时切男主短暂窘迫；圣女回怼的重音落在她的脸部近景，再用公子笑容僵住的短反应接住尾音；回双人镜时二人已开始转身离开，不重新起步。未来提交仍须另写逐镜时间与真实资产职责。

验收应连看插镜前后：反应是否由刚听到的信息触发、对白尾音是否完整、回到中景时动作是否继续、脸部镜头有没有增加新的情绪信息。单纯裁大原图或增加硬切数量不等于更顺畅。

### 从脚拍到脸：先选上摇还是升机

“往上拍”至少有两种不同结果，先选一种，不混写：

- **原地上摇（tilt up）**：机位高度不变，镜头俯仰转向上，落幅仍为低角度仰视人物；背景透视与仰角变化明显。
- **摄影机升高（pedestal/crane up）**：摄影机从腿附近上升到胸/眼高，可用轻微俯仰补偿；终点可得到接近平视脸部的构图。

原创 7 秒上摇例：A 已经站定。摄影机离地约 35 cm，位置和焦段固定。0–1.5 秒画面只见靴子至小腿，双靴在下方中偏左，接地点有留白；1.5–5 秒沿同一人物缓慢上摇，依次经过膝、腰间佩剑、胸肩，脸在后半程才越过上边界进入；5–7 秒停止摇动，落在胸口以上低角度近景，头顶留白约 5–8%H，脸在水平中间附近，视线朝画面右侧，右侧留出看向空间。焦点沿可见身体部位连续跟随。不拉远成全身，不把摇镜误做人物长高，不横向环绕，不在中途切镜。

起幅与落幅图要由同一空间和同一机位机制成立：固定低机位上摇不能落成平视俯拍脸。如果模型无法完成稳定一镜，可拆成“脚部特写→腰部细节→脸部近景”三镜，但交付时明确这是剪辑替代，不是连续上摇。

### 新人物进入：先规定空位，再规定怎么填

原创固定镜头例：A 坐在近景左侧，肩头在下方，B 将从画面右后方门口出现。开场门口为空；B 的手先推开门，再跨过门槛，身体沿后右→中右的斜线移动。落位在 x=65–70%W，停下时膝以上可见、高约 70%H，不穿过 A 的脸。开始焦点在 A，B 站稳后才缓慢转到 B；若要保持 A 的反应为主，则全镜不移焦。两种焦点方案选一，不同时要求前后都最清楚又极浅景深。

新人可以通过画边、门后、前景遮挡后、由底边起身或摄影机转向被发现而出现。逐镜按需要选，不把“所有新人都先拍脚”当规则。

## 4. 运镜设计卡：运动服务情绪与信息

运镜是独立设计环节。以下是原创方法，不是来源作品的逐帧测量。专业感看运动的理由、路线、速度、停点和连续性，不按运镜数量判断。

每个镜头用一行或短卡明确：

`触发/目的 → 起幅与轴线 → 运动机制/路径 → 起动、移动、减速的时间 → 落幅与焦点 → 同步对白/表演 → 接下镜的方式`

按需写实际秒数和可见裁切，不必堆焦距、轨道长度等无依据数字。优先一个主运动；需要组合时写先后关系，不能同时快速前推、下降、环绕还锁死同一构图。全片检查快、慢、固定的对比，不机械轮换。

### A. 惊讶/认知突变：快速推近后停住反应

- 刺激先成立：听到意外关键词或看清证据，表情与推进随之启动。不能镜头先推完、人再等一句话才惊讶。
- 起幅留出推进空间，例如胸口以上近景；沿视线轴附近快速前移，落到额头至下巴的脸部特写，眼睛始终在可读区域，给看向对手的一侧留空。
- 快速起动，接近落幅时短促减速，停住让观众读到眉眼、呼吸或嘴角变化；不要推到鼻孔、穿过头部或来回抽动。示例可将推进安排在约0.4–0.7秒，具体按镜头距离与表演调整，不作为固定规范。
- 选择一种实现：实体快速前移（fast push-in）应有与移动匹配的透视/前后景关系变化；机位不动的快速变焦（snap zoom）是另一种强调，写明不用实体前移；后期数字裁切是后期处理。三者不混称，切到一张大脸也不是连续推近。
- 重点只在少数真正的情绪突变处。反复每句推脸会消解力度，制造喜剧或机械感，不默认加巨响、径向模糊和震屏。

### B. 紧张/疑虑积累：缓推形成压力

- 从中近景缓慢接近到更紧的近景或特写，摄影机在同一侧稳定移动，主体周围的空间逐渐减少；不用每秒换构图来证明“在动”。
- 推进过程中要持续有信息：听到危险解释、找不到合理答案、目光避开等。让对白和听者反应继续，不为拍缓推而把语速也变慢。
- 选定重点句或意识到危险的瞬间收住，不漫无目的越推越近。过窄景深导致眼睛失焦、黑暗中只见轮廓，都不算紧张感通过。
- 缓推与全段慢动作不同；不要为了紧张给本来利落的转头、抬手、发声全部降速。

### C. 新人物/造型展示：先定“展示后知道什么”

- **从脸揭示到半身/全身**：若要结尾同时看到完整人物，采用摄影机后移拉开，必要时轻微调整高度和俯仰，让衣服、持物、站位逐步进入。不是“从头向下摇”就能同时保留头脚。
- **从头向身体扫描**：机位原地向下转动是下摇（tilt down）；摄影机实际降低高度是下降（pedestal down），可用俯仰补偿。依次让脸、胸口身份标识、腰间佩物进入，前面部位可以离画。写清落在哪个部位，不能又要从头到脚扫描、又要每刻整个人完整居中。
- **由脚向脸揭示身份**：使用前文上摇/升机方法，服饰或动作先提供线索，脸在后面揭晓；不是所有新人物固定从脚开始。
- 展示服装、职业、权力或危险线索，不无理由扫身体。人物应有自己的行动状态：落座、整理袖口、握住令牌等；不可为了展示就重置成静态设定板姿势。
- 已在对话里清楚介绍的人物不额外补长篇展示。可把展示融合进首次入场、抬手或走近，不能挤掉关键因果对白。

### D. 转移注意力：横移、跟随、短摇与固定镜的分工

横移可越过前景遮挡揭出新证据；跟随服务人物路径，必须给运动方向留路；短促摇镜可接突然的声音或视线，但要有看得清的终点。环绕只有在确实改变人物关系/揭示空间时使用，先检查轴线与遮挡，不默认整圈炫技。固定镜可提供清楚的动作接触、对话关系或给前后快推提供反差，不等于缺少设计。

## 5. 图像与视频验收

- 分镜图：能否直接指出人物中心、裁切线、主焦点、肩膀占边和运动预留区？如果只有漂亮的人物肖像，没有这些关系，就还没完成构图设计。
- 过肩：不是肩膀完全消失的单人近景，也不是背影堵满画面的后脑特写；另一人的脸和关键动作仍有可读空间。
- 脚到脸：确实由同一人物下身连续揭示上身；人没变高、机位机制没跳；到脸后有可观看的稳定落幅。
- 新人出场：初始空位、进入路径、遮挡、可见部位和终止站位都能核对；没有开场就出现、瞬移或毫无理由变成正面全身照。
- 运镜：主体移动、摄影机移动和背景视差彼此相容；画面停点不是只靠 prompt 的形容词想象出来。
- 运镜节拍：触发是否先有依据、速度是否体现情绪、落幅是否可读；区分前移、变焦、后期裁切和硬切。近景不能推歪脸，展示不能改变身体比例或衣物，缓推不能拖慢对白。
- 参数冲突：来源正文中的画幅、时长、数值若互相矛盾，先解决，再用于新任务。长文本和昂贵摄影名词不自动带来更准确画面。
