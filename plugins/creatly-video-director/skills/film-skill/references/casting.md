# 电影角色选角与形象生成

适用于电影人物设计、选角图、角色重做与正式角色参考。用户审美目标是：自然真实，同时有银幕吸引力和辨识度，脸能承载剧情。真实、魅力、特色、表演适配要同时考虑，不能只完成服装和年龄描述。

角色生成方法：`media-generation.md` 的“左头肩、右全身”用于面孔选定后的角色资产整理，不能作为所有选角图的默认版式。用户当前指定的风格、画幅、数量和参考身份优先；风格化电影沿用其媒介，不能一律改成真人摄影。

## 1. 先回答为什么选这张脸

每个主要角色先用一段选角简报连接剧情、面孔与表演。可以使用 [选角简报模板](../assets/Casting_Brief.template.md)，内容能从上下文确定时直接填写，不逐项询问用户。

- **戏剧任务**：观众初见应感受到什么，之后需要改变什么判断？角色在这场戏想得到什么、正在隐藏什么？
- **吸引力方向**：明确本角色主要靠什么吸引镜头，例如锋利英俊、清秀灵动、成熟沉着、粗粝魅力、亲和而难测。可以同时具备两种，不把帅、美、成熟与剧情适配设成互斥选项。
- **面孔记忆点**：挑两三个互相协调的主要特征，至少涉及脸部结构或五官关系；帽子、发型和服装只能辅助识别。把脸想象成去掉配饰后的近景，仍应能区别于其他角色。
- **自然差异**：用一两处合适的细微不规则打破模板感，如眉高微差、鼻梁线条有转折、嘴角不完全对称。它们是设计选项，不是每个人必须具备的瑕疵清单。
- **表演抓手**：写出一个可见的、当下发生的反应，而不是只列“聪明、神秘、有故事”。

年龄、经历和外观相互匹配。年轻角色可以非常好看、整洁、皮肤良好；自然不要求疲惫、显老、粗糙或降低颜值。成熟感也来自注意力、姿态、节奏和面部结构，不是把皱纹、白发全部加重。

## 2. 用具体结构创造特色，保留整体吸引力

先确定整体轮廓及比例，再选择少量关键部位。示例词汇用于设计，不应整表塞进提示词：

| 层面 | 可以明确的可见选择 | 需要检查 |
|---|---|---|
| 脸部结构 | 较长的中庭、宽颧窄颌、略方而柔和的下颌、清楚的眉骨与太阳穴转折 | 与年龄、体型协调；不能全员同一尖下巴 |
| 眼周 | 上眼睑厚薄、眼裂形状、眉眼距离、眉形节奏 | 眼神可读且眼睛结构自然，不靠放大瞳孔或锐化补救 |
| 鼻唇 | 带轻微转折的鼻梁、真实鼻尖肉感、清楚唇峰、上下唇厚度差 | 保持整张脸有吸引力，不把所有部位都做成“完美标准件” |
| 自然纹理 | 少量肤色变化、真实发际线、唇部与眼周正常细节 | 无蜡感、过度磨皮，也无夸张毛孔和刻意脏污 |
| 镜头气质 | 放松时亲和、集中注意力时锐利；外表稳重、短暂迟疑时显出脆弱 | 写成表演目标，不能仅凭长相断言真实智力、善恶或人格 |

真实感来自结构、表情、光线、姿态和材质一致；添加毛孔、胶片颗粒、痘印不能单独补足电影感。也不要批量加疤、痣、异色瞳来制造“特殊”，除非它们符合具体创作方向。

用户要帅或美时，明确表达主角级吸引力，并描述吸引力如何落在骨相、比例与表演上。不要用“普通、无存在感、路人”抵消用户要求；角色职业平凡不要求演员面孔平庸。男女角色均可俊美、成熟、机敏、粗粝或有压迫感，不给女角默认套甜美模板。

## 3. 先试镜选脸，再建立角色参考

### 尚未选定面孔

先探索真正不同的选角方向。方向数量遵循用户请求；没有数量时可先给两到三个简短方向，并在已获生图授权的范围内制作候选。只要一张就交付一张，不能把多轮、多张测试变成强制成本。

候选差别应至少来自两项：脸部轮廓/比例、五官关系、年龄气质或表演方式。只换头发、帽子、衣服、灯光或表情，不算换了演员。

首张候选优先单人头肩或胸像，让脸占画面足够面积。默认在统一白天户外自然光环境下比较；已生成的剧情候选可保留作为面孔来源，再制作标准组照，不因更换背景重新选脸。候选达到可比较程度后即可做下述多角度与多景别检查，不必等最终选角才看侧面和体态。用户只要一张时不擅自扩张为整套。

用户已有演员参考或认可的面孔时，以其身份锚点为准；用户未要求重新选角时，不为“增加特色”改骨相或擅自添加瑕疵。

### 标准选角组照：统一背景、同一候选、多角度与景别

默认采用同一处简洁的白天户外环境与自然日光，背景保持不过度抢眼；不预设浅灰棚拍背景或室内窗边场景。用户明确指定其他环境时跟随其选择。同一轮所有候选保持相同地点、相近时段、相近天气与光线方向，以及统一的曝光/白平衡和基础服装要求。避免直射日光使人物持续眯眼、树影斑驳遮住五官，或背景亮度压暗面部；在同一地点选择面部清楚且自然的位置。按视图采用一致的相机高度和透视，同景别保持相近人物占比。眼镜帽子等已指定角色特征保留，各视图穿同套衣服；表情先保持自然放松，目的是比较演员本身。背景统一不意味着把脸磨平或打成无立体感的证件照。

默认完整比较组为六个真实不同视图，按用户数量和本轮范围裁减；不能把所有候选、角度、表情做自动笛卡尔积：

| 视图 | 画面要求 | 判断重点 |
|---|---|---|
| 正面面部特写 | 全脸含下巴，发际与耳侧轮廓尽量可见 | 眉眼关系、比例、自然不对称、皮肤 |
| 左前45°头肩近景 | 摄影机在人物左前方，看见人物左脸更多，鼻尖朝画面右侧 | 颧骨、鼻梁、下颌和立体转折 |
| 右前45°头肩近景 | 摄影机在人物右前方，看见人物右脸更多，鼻尖朝画面左侧 | 另一侧结构，观察天然差异 |
| 左侧90°头肩近景 | 明确人物左侧面，鼻尖朝画面右侧，头与躯干自然协调 | 额鼻唇颏关系、侧面是否仍有辨识度 |
| 正面腰部中景 | 头到腰，肩颈和自然手部姿态可见 | 身体姿态、肩背、气质与服装关系 |
| 正面全身景 | 头顶到鞋完整，保留上下边距，无夸张广角 | 身材比例、重心和整体银幕形象 |

左右以人物自身为准，同时写明哪侧面可见及鼻尖朝向；不得用水平翻转制造反侧图，镜像会把真实不对称和饰物位置一起翻错。正面与45°保持双眼自然可读；90°侧面允许远侧眼被遮挡，不为了露出双眼把脸扭曲。不同景别需真实改变构图与可见身体范围，不把同一张脸裁成几个尺寸充当新视图。

执行顺序：为每个候选指定自己的清楚面孔图作为**临时身份锚点**，先查看它，再把它作为后续图像编辑/生成的实际参考。临时身份锚点只用于保持这一组是同一个人，不代表用户已批准选角。其余视图都回指该候选锚点及确有必要的已验收视图，不把每一张新脸串接为下一张唯一参考，避免累积漂移；A与B绝不能混用参考。

优先生成独立原图并逐张检查，再用当前允许的图像工具整理成固定顺序的2×3比较板。用户只要一张组图时，可直接生成多视图比较板，但逐格检查身份与角度，不把一张板称为六张独立原图。比较板用于快速选择，原始单图若有则保留供放大和后续生成使用。生成数量按用户实际请求，统一背景讨论本身不自动授权批量生图。

验收一组时，对照眉形、眼距、鼻唇轮廓、耳形、发际、年龄与已存在的自然差异；不要把光线或透视的正常变化误判为换人，也不要为保持相似而把各角度生成成同一个正面。角度通过与身份通过分别记录，失败只修正对应视图。单张漂亮但换角度就换脸，不能作为合格的角色组照。

### 面孔初选后

根据任务需要，检查同一角色在一个具体剧情反应中的可信度。例如从阅读协议转向老板，或听见含糊回答后暂不接话。静态图片只描述所捕捉的一瞬；前后两个表演状态用两张图或后续试镜视频验证，不声称一张静图证明完整演技。

最终选定后沿用已验收组照的身份，补齐未覆盖的正式服装与道具设定；这时可按需要整理左头肩右全身的标准资产。选角阶段已有合格全身或侧面图时直接复用，不为流程形式重复生成。不要每张都从纯文本重抽一张相近但不同的脸。

用户有连续推进授权时可在授权内推荐并采用候选，清楚记录依据；没有选定依据时标为待选，不自行把生成成功写成选角通过。用户说“这些角色不好”时，旧图标为退回重选，保留文件但移出默认身份参考，除非用户明确要保留其中某张脸。

## 4. 把性格写成可拍的反应

对“智慧眼神”的处理：先明确他注意到了什么，再设计注意力和微表情。比如正在读入住条款，听见老板换了一个词，目光从纸上抬向说话人，眉间仍松，嘴唇微停，暂不说破。单张图捕捉抬眼后的那一刻。

选择与情境有关的两三项即可：注视对象、身体与头部朝向、眼睑自然状态、嘴部张力、回应前停顿的姿态。避免同时堆“智慧、锐利、警惕、深邃、温柔、冷酷”等互相竞争的词。

老板的“难看透”可以是礼貌笑意尚在、视线已转到签名栏、身体没有催促；不靠阴森打光和奸笑。女角的“机灵”也可以是耐心听完再回应，不必大眼睛加甜笑。

这些都是表演设计选择，不是声称特定眼型或面相代表聪明、可信或邪恶。

## 5. 提示词结构与示例

顺序：用途与媒介 → 角色/剧情目标 → 吸引力方向 → 两三项面孔特征 → 少量自然差异 → 当下表演与视线 → 简洁服装背景 → 清楚可读的摄影 → 必要局部限制。

优先写人物和表演，把“电影感、超真实、高级、8K”等泛词换成可见信息。只保留与已有失败有关的限制；不要长篇负向词把帅、美、情绪与个性都削掉。

下面为标准组照之后的剧情试镜示例，旅馆背景不用于替代白天户外标准组照。以下是一种新选角方向，不是当前项目已批准的男主身份；有锁定参考脸时不能套用这些新五官。

> 写实悬疑电影的男主选角试镜照，24岁中国成年男性，英俊、有辨识度，年轻人进入陌生旅店时仍试图保持镇定。单人胸像。脸型偏长，清楚的眉骨与较舒展的颧部过渡形成轮廓，鼻梁有一点自然转折，下颌收得利落但不尖；嘴角有轻微高低差，保留年轻人的面颊饱满度和自然肤色变化。黑色短发露出眉眼。画面捕捉他从入住协议上抬眼、望向镜头旁老板的瞬间：身体还朝柜台，目光已集中到说话人脸上，眉间放松，嘴唇微停，像注意到答复中的矛盾而暂不说破。深绿色旧夹克只露出领口。模糊的旧旅馆暖色背景，一侧柔和光线显示眼窝和鼻梁的立体关系，暗侧保留细节，双眼清楚。不摆时装姿势，不用磨皮或怒目代替表演，无文字。

若制作对比候选，应为另一张设计不同的轮廓、五官关系和吸引力，而不是替换示例里的形容词就称为新方向。

## 6. 看图验收与定向修正

实际查看生成图，依据下面五项给出“通过 / 待调整 / 淘汰”及简短可见证据，不依据提示词声称图中已经实现。证据比总分重要，不用打分掩盖关键问题。

| 项目 | 验收问题 |
|---|---|
| 自然可信 | 骨骼与软组织、肤质、眼睛反光、年龄、头颈姿态是否一致？是否像磨皮头像、蜡像或过度锐化皮肤？ |
| 吸引力与记忆点 | 能否说出这张脸的两处具体特点？有没有本角色需要的俊美、成熟或其他明确魅力？特色是否只剩衣帽？ |
| 剧情与表演 | 标准组照检查自然放松的状态、体态与角色基础气质，不要求演具体剧情；剧情试镜再检查此刻看谁、想什么，以及是否通过可见反应进入这场戏。 |
| 候选与群像区分 | 候选是否真是不同演员？主要角色去掉服装后，在轮廓、年龄层、五官节奏与表演上能否区分？ |
| 身份与资产一致 | 标准组照各角度、景别是否同一个人，且视图确实不同？是否混用候选或用镜像/裁切冒充？未生成的角度不能算已验证。 |

自然可信、目标魅力或剧情适配有关键缺陷时，不能因“图已生成”“衣服正确”而交付为正式角色资产。可以向用户展示探索稿，但如实指出不足和下一步。

修正先区分：

- **演员不对**：保留年龄、剧情需求等已定条件，重设计骨相和吸引力方向；拒绝图不作为脸部锁定参考。
- **演员对，表演不对**：锁定面孔，仅改注视对象、微表情或姿态。
- **人对，摄影不对**：保留身份与造型，调整光、距离、背景和皮肤处理。
- **单图好，跨图不像**：回到已选身份参考，重做漂移资产，不用多个近似面孔混充同一人。

采用有限的定向修订，不把反复抽卡当优化；同类问题修正后仍存在，展示差异并明确待解决点，避免无界生图。文本策略通过不代表实际画面通过，最终选角仍以看图与用户反馈为准。

## 7. 交付与任务边界

交付候选图片及一句选角理由、主要区别、验收结果、身份是否锁定。保存实际提示词、图片路径和修订原因；有需要再维护完整选角简报，不强迫每次小修改填长表。

只要求优化技能时，修改规则、同步安装与交付文件即可，不擅自额外生成角色。用户要求出图时使用当前可用图像工具，遵循其调用要求；工具不返回底层模型时只记录工具名称，不编造具体模型版本。
