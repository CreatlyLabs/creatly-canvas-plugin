# Film 工作计划方法

## 产物

这份 Skill 的唯一产物是一份**可审的制作计划**。可审的意思是：另一个人只读这份计划，就能判断它是否成立，并指出该改哪里——而不需要先去看画布或问作者。

计划必须覆盖以下八项。任何一项缺失或只有空壳，计划都不算完成：

| 组成              | 判据                                                         |
| ----------------- | ------------------------------------------------------------ |
| 故事与剧本        | 完整成段，不是提纲；改编时说明保真边界与取舍                 |
| 制作圣经          | 世界、视觉、声音、角色、场景、道具与连续性常量已固定         |
| 资产规格          | 每个跨镜主体有固定描述、状态版本、使用范围、依赖与验收标准   |
| Scene / Shot 设计 | 每镜有叙事目标、人物任务、时长、景别、主要动作、复杂度、转场 |
| 最终提示词        | 可直接用于生成，不是待细化的描述                             |
| 连续性风险        | 针对本片的具体风险，不是通用清单                             |
| 生成批次          | 明确的依赖顺序与每批范围                                     |
| 返工计划          | 指出最可能需要返工的镜头及其应对                             |

计划的写入、审批与付费不属于这份 Skill。它只负责让计划本身成立。

## 一、故事与剧本

先识别输入类型——创意扩展、梗概扩写、忠实改编，还是参考素材引导——不同类型的保真边界不同，混淆会导致改编越界或扩写不足。

按对应边界形成：一句话故事、人物目标、主要阻力、关键转折、结尾兑现。归并角色的姓名、称谓与别名，形成角色功能、关系、目标、缺口、变化方向与保留必要性。

产出「故事方向」部分：一句话故事、主线与必要副线、角色及关系、关键转折、结尾方向，以及保留 / 合并 / 省略 / 新增的取舍。存在分歧时明确列出待决项，不要替用户选。

随后区分**剧本事实、强推断、导演提案和阻塞冲突**——这四类不能混写，否则审阅者无法判断哪些可以改、哪些改了会破坏原作。据此形成国家年代、世界规则、空间顺序、人物小传、状态顺序、关键道具与文字情绪曲线。

## 二、制作圣经

按 [制作圣经与镜头工作台](production-bible-and-shot-workbench.md) 固定世界、视觉、声音、角色、场景、道具与连续性常量。

角色表演基线写**目标、阻力、策略、身体任务，以及压力下的声音变化**，不要只写情绪形容词——「紧张」无法指导表演，「想推门却先回头确认走廊」可以。

## 三、资产规格

只为需要跨镜保持一致的对象建立资产：角色、必要状态、固定空间、叙事关键道具。不跨镜的一次性元素留在镜头里。

按 [主体创建](subjects.md) 形成资产登记表，每项含固定描述、状态版本、使用范围、依赖与验收标准。基础角色与叙事状态分开：只有会改变跨镜识别的换装、年龄、伤势或变异才创建独立状态。

明确资产之间的**依赖顺序**——参考图依赖什么、谁必须先于谁完成。这个顺序直接决定生成批次的划分。

## 四、Scene 与 Shot 设计

先形成全片方案再进入细节。按 [分镜与提示词](storyboard-and-prompts.md) 为每个镜头写明叙事目标、人物任务、时长、景别、主要动作、复杂度与转场。

按 [场景设计与连续性](scene-design-and-continuity.md) 检查重复场景的空间一致性与跨镜连续性。

选出 1 到 3 个**代表镜头**作为试拍对象，并说明选择理由：它们应当覆盖本片最高的不确定性，而不是最容易成功的镜头。

## 五、最终提示词

按 [分镜与提示词](storyboard-and-prompts.md) 编译每个 Frame、Video 与可选 Audio 的最终内容。

提示词要能直接投喂生成，不是「一个昏暗的房间」这类待细化描述。编译前完成镜头审计：首帧占位、空间、视线、物理、表演、时长与残留引用。

质量要求见 [导演质量控制](director-quality.md)。

## 六、连续性风险

列出**本片的**具体风险，不是通用清单。每条风险指明：在哪些镜头之间、什么会漂移、如何检查。

「角色服装可能不一致」没有价值；「第 3 镜到第 7 镜跨越雨中场景，角色外套的湿痕状态需要保持，检查袖口与肩部」才是可执行的。

## 七、生成批次

按资产依赖顺序划分批次，说明每批的范围与前置条件。主体参考图先于依赖它的镜头，试拍先于扩量。

批次划分只表达**依赖与顺序**。每批的报价、确认与提交由 Film Product 与宿主执行层负责，这里不写。

## 八、返工计划

预判最可能需要返工的镜头，说明理由与应对方向。

返工时的判断方法见 [修改传播与镜头迭代](revision-propagation-and-iteration.md)：一次只改一个主动变量，先修最上游的真实原因，同类问题约三次不改善就换思路。

**定向返工的边界要写清楚**：改这个镜头会波及什么、不该波及什么。这决定了一次返工是精准的还是全量重来。
