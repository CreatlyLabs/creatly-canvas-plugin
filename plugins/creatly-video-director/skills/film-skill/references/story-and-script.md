# 故事与剧本

## 目标

把用户的创意转成一个可直接拆分 Scene、Shot、Frame 和 Video 的短片剧本。最终剧本写入 Script 节点，不在聊天中暴露内部推理过程。

## 先归一化创作要求

从请求中提取：

| 维度 | 内容                                     |
| ---- | ---------------------------------------- |
| 作品 | 名称、类型、受众、平台                   |
| 叙事 | 主角、目标、阻力、赌注、转折、结尾       |
| 规格 | 总时长、画幅、语言、节奏                 |
| 视觉 | 风格、时代、地域、色调、禁用元素         |
| 声音 | 对白、旁白、环境音、音乐                 |
| 资产 | 已有角色、场景、参考图片或必须复用的主体 |

缺少会改变主线或费用的信息时一次询问。用户只允许补齐未指定的制作参数时，可以对时长、画幅等非创作方向使用明确而保守的默认值，但这不等于授权跳过故事、剧本或分镜确认。

## 标记信息来源

按 [导演质量控制](director-quality.md) 区分剧本事实、强推断、导演提案和阻塞冲突。只有会改变剧情、主体或付费范围的冲突才阻塞流程；其他未写明内容先给一套推荐，不要求用户填写空表。确认后的结论成为后续主体、分镜和提示词的共同制作设定。

## 识别改编模式

不要只按字数判断输入。先识别素材完整度、用户要求的忠实程度和目标成片时长，再选择一种模式：

| 模式     | 适用输入                 | 可以补充                           | 必须保留                                       |
| -------- | ------------------------ | ---------------------------------- | ---------------------------------------------- |
| 创意扩展 | 一句话创意、角色或局面   | 人物姓名、因果链、冲突、转折和结尾 | 用户给出的核心设定与禁区                       |
| 结构扩写 | 故事梗概或不完整场景     | 可见动作、场景连接、对白和节奏     | 主线、人物关系、关键事件和结局方向             |
| 忠实改编 | 网文、完整故事或定稿文本 | 为可拍摄性进行合并、压缩和顺序调整 | 事实、因果、角色动机、标志性事件和用户指定台词 |

用户要求保留原作时，不擅自加入身份反转、逆袭、爱情线或新反派。长素材按完整戏剧单元和目标时长拆分，不使用固定字数阈值机械拆集；每一集都要有独立目标、局势变化和自然的结束点。

改编前建立简短变更账本：

```text
保留：原素材中不能改变的事实、人物关系、事件和台词。
合并：为时长或制作可行性合并的人物、场景或事件。
省略：删除的支线及其不影响主线的理由。
新增：为补足因果或可拍摄性增加的内容，并标记为导演提案。
```

变更账本的最终结论写入 Script 的制作设定。它用于防止后续拆镜时再次自由改编，不要求把内部推理过程写给用户。

## 建立最小故事骨架

先形成以下内部创作骨架，再写剧本：

```text
一句话故事：谁为了什么，在什么阻力下采取行动，最终发生什么变化。
主角目标：可见、可行动、可在片中验证。
主要阻力：人物、环境或时间压力。
赌注：失败会失去什么。
转折：新信息或行动改变局势。
结尾兑现：回答开头提出的主要悬念，或留下用户要求的钩子。
```

短片不要并行展开过多副线。30 秒左右的作品通常围绕一个目标、一个核心冲突和一个主要转折。

## 两轮锁定故事结构

完整成片和长素材改编先锁结构，再写逐场剧本：

1. **快版骨架**：只确定主线、角色功能、主要场景、关键转折和结尾兑现。检查因果是否闭合、目标时长是否装得下，以及哪些人物、场景或事件需要合并。
2. **细版剧本**：吸收用户确认或已授权的导演决定，再补可见动作、对白、场景连接、状态变化和声音设计。

快版结束时必须展示「故事方向确认包」，至少包括：

- 一句话故事、主角目标、主要阻力和赌注；
- 主线、必要副线及其关系；
- 角色名册、角色功能、人物关系和变化方向；
- 保留或删除的支线、合并或保留的角色；
- 关键转折、高潮与结尾方向；
- 仍存在的导演提案和会改变故事的分歧。

默认停在这里，结束当前回复并等待明确确认。Agent 不能在展示方案后自行继续。只有用户在当前任务中明确授权 Agent 自主决定故事、角色、剧本、资产和分镜，并要求不中途确认，才能直接进入细版；选择快速模式或只说「开始制作」不能跳过本确认点。自主执行时仍须把决定写入变更账本。

不要在故事结构尚未稳定时制作完整角色卡、场景参考图或逐镜提示词。上游角色、场景或事件发生变化后，重新检查所有下游 Scene、Shot、主体和连续性引用，不能只修改 Script。

细版剧本完成后，按 [制作圣经与镜头工作台](production-bible-and-shot-workbench.md) 形成制作常量，再展示「剧本与制作圣经确认包」：完整剧本、角色身份与行为摘要、场景和关键道具清单、状态变化，以及世界、视觉、摄影和声音常量。默认再次结束当前回复并等待确认；确认前不创建主体、不拆 Shot，也不编写 Frame 或 Video 提示词。剧本与制作圣经确认后，再单独展示资产清单并等待确认。

## 固定导演意图

完整成片在写剧本前按 [导演质量控制](director-quality.md) 形成导演包。至少固定观众体验、关键兑现、视觉规则、角色身份锚点和场景空间图。最终结论必须进入可见画布内容，不能只留在内部推理中。

## 时长与信息预算

先估算目标镜头数：

```text
目标镜头数 = 总时长秒数 / 5，向上取整
```

这只是初始预算。对白、复杂动作和情绪停顿需要更长镜头；单一反应或插入细节可以更短。

对白时长参考：

| 状态       | 参考语速   |
| ---------- | ---------- |
| 急促、争吵 | 约 4 字/秒 |
| 正常对话   | 约 3 字/秒 |
| 悲伤、低语 | 约 2 字/秒 |

在估算结果上增加标点停顿、动作和约 1 秒安全余量。不要把念不完的对白塞进 3 秒镜头。

## 剧情视频写作原则

### 尽早进入事件

- 第一场尽快出现异常、选择、冲突或明确目标。
- 用行动和有功能的对白交代关系，不写长段背景说明。
- 在短片前段提出观众需要追看的问题。

短剧类型可以使用开场钩子、逐级加压、转折兑现和集尾悬念，但这些是类型策略，不是所有广告、MV、动画或剧情短片的固定公式。钩子必须来自人物目标、风险或关键信息，不能靠与主线无关的冲击画面硬加。

### 每场都有变化

每个场景至少完成一种变化：

- 信息变化；
- 人物关系变化；
- 目标或策略变化；
- 情绪强度变化；
- 空间或时间变化。

若一场结束后局势与开始完全相同，合并或删除该场。

### 用可见行为表达

把心理状态转换为可拍摄信息：

- 动作和身体反应；
- 表情与目光；
- 具体台词或停顿；
- 环境对人物的影响；
- 必要时使用简短 OS 或 VO。

不要写「她非常纠结」这种无法直接成像的句子。改写为具体选择、迟疑动作、回避目光或被打断的台词。

### 控制情绪

一部短片集中在 1 到 2 个核心情绪。通过行动、语言、环境和必要独白保持一致推进。配角的情绪不能掩盖主角的叙事中心。

### 保持角色一致

为主要角色固定：

- 一到两个性格关键词；
- 说话习惯；
- 一个可识别动作或习惯；
- 初始状态和片尾变化。

每个变化必须由片中事件触发，不要突然改变立场。

### 让对白承担功能

- 单句尽量控制在 20 字以内。
- 每句至少推进信息、关系、冲突或决定之一。
- 保持口语自然，避免半文半白和抽象口号。
- 不重复画面已经清楚表达的信息。
- 同一 Shot 内避免多角色多轮往返对白。

## 剧本格式

Script 节点使用以下结构：

```markdown
# {作品名}

目标时长：{时长}
画幅：{比例}
类型：{类型}
视觉风格：{风格}

## 导演意图

观众体验：{开头、转折和结尾的情绪变化}
视觉母题：{反复出现并承担叙事作用的动作、道具、颜色或空间关系}
视觉规则：{媒介、色板、材质、光线、镜头、构图和后期质感}
关键兑现：{最重要的信息或情绪如何通过可见行为完成}
禁用项：{不应出现的元素、风格和镜头语言}

## 摄影与声音基准

影视参考：{主要参考及具体借鉴维度，必要时补充一个单一维度参考}
拍摄与镜头：{媒介、摄影机或胶片、镜头家族、画幅与帧率}
曝光与色彩：{光源、高光、暗部、反差、肤色保护、允许色和禁用色}
纹理与材质：{颗粒、锐度、光晕、镜头缺陷和材质反射}
人物声音：{主要角色的音色、口音、语速和压力状态}
环境与动作声：{各类空间声和同步动作声原则}
音乐：{使用节点、乐器、频率重心、动态、留白和禁用声音}

## 项目制作设定

类型与现实程度：{类型、世界可信边界}
国家、地域与年代：{具体范围及技术、建筑、服装限制}
季节与时间：{季节、天气、昼夜、剧情时间跨度}
语言与声音文化：{语言、口音、语速与表达差异}
世界规则：{超自然、伤害、死亡、变异或其他规则}
空间顺序：{主要空间及其方向和因果连接}
人物关系与小传：{目标、缺口、关系、人物变化和生活痕迹}
状态顺序：{换装、伤势、污渍、变异、道具转手和环境变化}
关键道具：{尺寸、材质、磨损、方向、持有人和状态变化}

## 全片情绪曲线

| 节点 | 剧情位置 | 事件       | 强度       | 升降原因 | 声音重点                         |
| ---- | -------- | ---------- | ---------- | -------- | -------------------------------- |
| 1    | {位置}   | {事件短名} | {0.0-10.0} | {原因}   | {环境声、动作声、对白或音乐策略} |

呼吸区：{节点及原因}
最高点：{节点及原因}
结尾余韵：{最后情绪落点}

## 剧情梗概

{主要冲突、关键转折和结尾，控制在能快速阅读的长度}

---

### 1-1 {场景名} {日/夜}/{内/外}

人物：{人物名，空格分隔}

{环境、光线、关键道具。}

{人物的具体动作、表情和空间关系。}

{人物名}：{台词}

OS（{人物名}，{情绪}）：{必要的内心独白}

[硬切]

---

### 1-2 {场景名} {日/夜}/{内/外}

...
```

格式规则：

- 场景标题同时说明地点、时间和内外景。
- 人物列表只列该场实际出现者。
- 动作描写写清「如何发生」，包括起始姿态、动作变化和反应。
- 环境描写包含主光方向、色温、明暗关系和关键道具。
- 场景之间用 `---` 分隔。
- 常规同场切换使用 `[硬切]`；淡入、叠化、闪白或闪黑只在叙事需要时使用。
- 不在剧本中加入创作过程、字数统计、自查清单、版本后缀或镜头参数表。

## 为竖屏调整剧本

画幅为 `9:16` 时：

- 让主要人物和关键动作集中在垂直构图中心区域；
- 减少依赖宽阔横向关系的场面调度；
- 多用前后景、上下层次、俯拍或仰拍表达空间；
- 双人对话保持双方位置和视线方向稳定；
- 关键道具应能在近景或特写中清楚辨识。

不要为了竖屏把所有镜头都写成近景。仍需用少量远景交代空间。

## 剧本自检

写入 Script 前逐项检查：

- 开头是否快速提出事件或目标；
- 改编模式是否明确，保留、合并、省略和新增内容是否遵守用户要求；
- 主角目标和阻力是否可见；
- 每场是否发生变化；
- 主要转折是否由前文信息支持；
- 结尾是否兑现主要冲突或按要求留下钩子；
- 动作、表情、光线和道具是否足够拆镜；
- 台词能否在目标时长内说完；
- 角色名称是否统一；
- 场景名称能否直接用于主体和 Scene Label；
- 视觉规则是否具体到色板、材质、光线、镜头和构图，而不是只有「电影感」等抽象词；
- 角色身份锚点和固定场景空间关系是否能够跨镜头复用；
- 剧本事实、推断和导演提案是否分清，确认结论之间是否冲突；
- 国家年代、世界规则、空间顺序、状态顺序和关键道具是否完整；
- 情绪曲线是否来自真实剧情变化，并包含呼吸区和最高点；
- 摄影与声音基准是否能直接约束后续 Shot；
- 是否删除了内部说明和无关元信息。

自检内容不写入画布。只写最终剧本。

## 写入画布

先把最终剧本准备为一个新节点定义：

```text
clientRef: script
type: script
label: 剧本
content: 完整剧本
```

完整成片在「剧本与制作圣经确认」后，把唯一 Script 作为独立小批次写入并回读真实 `scriptId`。后续每个 Scene 批次通过 `parentIds` 引用它；9 个 Scene 仍对应 9 个 Scene 原子创建批次，另有一个轻量 Script 写入。普通创建的 Audio 只保存内容和关系，不表示已经具备付费生成所需配置。

只写剧本的局部任务可以单独调用 `createNode`，但仍须传入最新 FULL 快照中的 `projectId`、稳定 `idempotencyKey` 和唯一 `clientRef`。实时 schema 提供的 `baseVersion` 只作可选冲突检查，不是全局 Compare-And-Set。

已有项目先从 FULL 快照确认目标 Script，只用 `updateNode` 更新明确对应本作品的真实 `nodeId`。写入后重新读取 FULL 快照，验证完整内容，并从该快照取得当前 `currentVersion`。
