# 来源与观察边界

## 实际浏览路径

日期：2026-09-13。通过本机 Chrome 的 Computer Use 打开 [Neowow 作品广场](https://neodomain.cn/neo-tv)，依次进入作者显示为 @命比梦长 的《万物生：问心》及《万物生》卡片的“查看创作过程”。两者均在只读画布中浏览。页面地址仍为作品广场地址，未获得独立公开画布深链。

用户给的 `play-overlay` 是《万物生：问心》卡片播放控件，不是提示词。研究依据是随后打开的生成节点、输入引用和实际图像，不是该 HTML 片段。

范围：抽样阅读场景开场、群像救援、横向动作、道具提取、场景重打光、表情修正、原作化妆间对白等节点；观察相关分组及多版本缩略图；高清查看一张人物设定图、一张场景截帧。**未逐个检查全画布所有节点，未完整逐帧观看两部成片，不能判断每个候选是否最终入片，也未取得作者内部 Skill 或完整创作历史。** 上传素材未显示原始生成提示词，不反推成“作者原文”。

以下是结构化转述，不保存作者整段提示词。

## 镜头顺序的补充核验

后续同日继续用浏览器打开《问心》成片（播放器总长 11:41），按时间轴暂停查看片头与前两分钟多个位置，重点核验约 03:35–04:40 的危机段，并回到画布读取对应/相关视频节点。详细时间点、提示词节拍及迁移规则见 [镜头顺序与信息揭示](shot-order-and-reveal.md)。时间点为播放器可见的取样位置，不是精确剪辑点。

重要更正：之前称作“开场部落”的节点是**部落危机段的开场**，不是整部《问心》的第一镜。成片真正开头是睫毛上的蚂蚁，再逐步扩展到两人躺在沙地上的处境。此前观察表不能用来推断成片顺序。

本次还读到了：沙地双人构成数字 2 的静帧设计、极远景静默后慌乱逃离、女主行走独白的三次运镜落点、庆典舞台与铁匠市集遮挡衔接、人物从打哈欠到示警的四镜安排、环绕转越肩后揭示巨物的长镜头。部分节点文字时长/画幅与 UI 参数不一致，部分文本在无障碍读数中截断；只使用确实读到的段落，必要时展开滚动检查。

仍未完成两部作品全片逐镜清单，也未听辨核验整片声音。以下音效设计结论来自节点文字，不能等同于成片音轨实际执行情况。

## 观察到的做法及可迁移含义

画面专项补充：按用户纠正，将研究重点从剧情转到机位、裁切、过肩遮挡、人物入画及占比。新增读取《问心》脚部倒退跟拍节点：机位 30–40 cm、左三分之一位置、约四分之一画宽、顶部裁在大腿中段，全程只拍腿，并非向上摇到脸。同时重新读取低角度起身入画、环绕转过肩的节点全文；在成片 02:44 的头部近景做目测占比。详见 [机位与构图细拆](camera-and-framing.md)，其中明确区分作者要求、实际帧目测与原创建议。本轮视频放大及浏览器连接不稳定，未完成“脚到脸”连续运动的成片核验，不将模板冒称来源实测。

| 样本 | 实际看到 | 可迁移做法 | 不应过度推断 |
| --- | --- | --- | --- |
| 《问心》开场部落视频节点 | 分别引用环境与色卡；大全景后接器皿、居民、动物、织物反应；每个小镜头含位置、光线、声响与运动 | 通过物体和人物对同一事件的不同反应推进信息，避免全靠空泛氛围词 | 多切镜提示词不等于所有模型都能稳定照做 |
| 《问心》高大铁匠穿行人群 | 人物/场景/色卡分工；通过人群与巨汉腰部的高度关系建立尺度；拥挤使其步态受限；前景有人遮挡 | 尺度用可见参照表达；动作受空间阻力约束，环境参与表演 | 该夸张比例服务喜剧角色，不是所有人物设计准则 |
| 《问心》横向收尾动作 | 首帧、两个角色、两类生物、环境、色卡各有职责；文字区分外观与姿态；持续横向跟移，背景反向视差；前景遮挡转黑作为衔接设想 | 明确引用控制范围；摄影机、主体与背景运动方向分别写清；为剪辑设计出入点 | 不能把大量素材原封不动塞进最多五图的模型；文字意图不代表实际视频完全实现 |
| 《问心》独立包袋图 | 从角色参考提取腰间道具，以中性背景单独展示，并限制符号形式 | 特写重要道具单独建资产，减少跨镜重设计 | 无需让每个无关物件都有设定图 |
| 《问心》场景重打光图 | 两张输入分别控制原场景和目标色彩；明确仅改光线，并列保留构图、物体位置与几何关系 | 局部编辑分成变化项与保留项，再对比输出 | 该节点正文提及一个模型，界面显示另一模型；这是应复核的矛盾，不复制其 API 操作指令 |
| 《问心》女性疑惑近景修正 | 从视频截帧重制，保留影调；另一人物参考只控制五官；表情拆成轻微歪头、眉眼和嘴部变化 | 表演可被拆成小而明确的可见动作，利用截帧修复连续性 | 不认为修正后的图片必然是作者最终采用版本 |
| 《万物生》角色设定图 | 高清图中左侧大脸部参考，右侧正背全身；中性背景；深蓝、黑、米白服装结构稳定，有轻微磨损 | 脸与全身承担不同信息量；服装结构、材质和独特识别点共同锁身份 | 该图是上传节点，未读取到它的原始制作提示词 |
| 《万物生》化妆间对话视频 | 引用人物、玩偶和音色；固定机位；明确前中后景和焦点；人物入画与台词时间相配；有结束姿态 | 表演调度、声音时序和空间构图一起设计，而非仅写台词 | 不机械照抄极长提示词、摄影数值或命名风格；实际输出仍需验收 |
| 《万物生》另一化妆间截帧 | 高清图见前景大玩偶与梳妆物，中景人物关系，背景窗光；暖侧光与冷窗光形成分区 | 用前景遮挡/物件、中景人物、背景光源建立层次，镜头不必人人正面全身可见 | 这张截帧与上行提示词不是已核验的一一对应关系 |
| 两个画布布局 | 素材和镜头分组，同题材画面有相邻多个候选；存在截帧、图片生成和视频生成节点关系 | 保存版本，组织资产到镜头的引用与迭代 | 无法由缩略图数量反推出准确重试次数、耗费或完整制作顺序 |

## 对本技能的改编，而非来源事实

- 逐镜确认是可选的项目确认方式；新技能按当前用户授权记录执行，不能声称来源作者也逐镜向用户确认。
- 打斗的重心、接触、道具归属表，及 `prompt-workbench.md` 的争剑示例，是为当前任务补充的原创方法和示例，不是《万物生》的原始分镜。
- 此次样本常强调实拍感，但用户的项目要求 CG，所以学习的是资产分工、构图、调度与迭代方法，而非换掉用户的审美方向。
- 网站角色图和作品属于其创作者；此技能没有打包其图片、整套原文、登录态或用户密钥。
