# 问心融合：镜头组与视频提示词

本规则融合画布项目内 `wenxin-prompt-director` 的视频框架、块切组合、导演方法和镜头语法。它是方法提炼，不是作者官方教程；不复制其剧情、人物、画幅或特定风格。所需规则已内置于本技能，不依赖网站旧部署目录或另一个技能的绝对路径。

## 先做决定，避免自动写成一镜到底

一个视频节点/生成请求是一个片段，可以承载多个摄影镜头；一个摄影镜头内部也可以有多个节拍。先问“观众依次需要看见什么”，再决定机位与切点。

- 对战、追逐、对峙、发现等有多个信息职责的段落，优先考虑镜头组，而不是默认一个机位拍到结束。每块选一个主要职责：建立、发起、证据、反应、升级或收束。
- 连续表演、空间探索或用户明确要求长镜头时，单镜可以更好；说明其视觉理由，用内部落点推进，不为凑数量强切。
- 多镜稿不能同时写“全段不切镜”“连续一个镜头”“全段不换机位”。角色一致性靠资产、空间和动作状态保持，不靠禁止切镜。
- 首尾帧是输入约束，不自动决定剪辑方式；只有同镜续接才继承相机和动作速度，换机位则重新设计起幅。
- 模型不支持或不能可靠执行段内多镜时，保留镜头设计，改为逐镜生成再剪的方案；额外提交或费用须在授权范围内，不擅自改成单镜。

## 选择最少但足够的镜头组合

| 观看需求 | 可选顺序 | 衔接要点 |
| --- | --- | --- |
| 发现 | 人物看 → 所见 → 必要的反应 | 视线方向匹配；不先给答案再演发现 |
| 对峙/对白 | 关系双人 → 发起者/过肩 → 听者反应 → 新关系 | 台词可跨切点落在听者；不每句机械正反打 |
| 快速动作 | 发起 → 接触 → 化解/反击 → 结果 | 同一动作前镜发起、后镜完成，不重复挥击 |
| 追逐 | 地理关系 → 跟随 → 障碍 → 越障 → 新距离 | 切前后屏幕方向、速度、落脚相位一致 |
| 揭示 | 痕迹 → 注意 → 证据 → 答案 → 后果 | 每镜新增证据，不堆近似漂亮画面 |
| 权力翻转 | 初始关系 → 触发 → 证据/反应 → 新构图关系 | 用占比、高低、距离改变主次，不只换焦距 |

按节拍删减，不固定每段四镜，不默认大全景开头，不把九宫格当九个候选。画格按成片顺序覆盖同一节拍；多格图须拆成单幅后才用作相应首帧。

## 时间安排

已知总时长或进入生成阶段时，为每镜写编号、起止时间和持续秒数。区间从零开始、递增、无空隙无重叠，总和等于请求总时长。用户只在探索、未定长度时可先写编号和拟定时长；说明是设计值，不冒充成片实测。

时长由动作可读性和信息量决定，不平均分配，不固定全部 10 秒。5/10/15 秒只是在模型支持时可选的请求长度；不能因创作想要 15 秒而绕过模型上限。快速打斗不等于每镜超短：保留读懂空间、接触和受力的镜头，去掉反复蓄力、停顿和摆造型。用户要快动作时不默认加入慢动作、定格或子弹时间。

时间码是目标，生成模型不保证逐帧服从；完成后测实际镜长和切点。尚未看片只能报告设计完成，不能声称时长、衔接和动作已验收。

## 最终提示词框架

最终稿从 `[STYLE LOCK]` 起，按下面顺序组织，省略无关字段，不留空占位符：

1. 媒介与视觉：已确认的风格、画幅、光线、材质、空间基底；用户要 CG 就保留 CG。
2. 参考职责：身份、服装、道具、地理、构图、色彩、音色或首尾帧分别由谁锚定。真实 `@资产` 原样保留，无句柄不编造；核实图确实传入且顺序匹配。人物设定图不锁站姿，多镜参考首图不锁全段机位。
3. 音轨：跨切镜持续的环境声；与接触同步的动作音；指定说话者的对白或画外音。配乐按需求，不能每次换镜都重启声音。摄影指令不作为台词读出。
4. 执行与连续性：总长、镜头数、剪辑方式、轴线、屏幕方向、持物手、目标物位置、服装、光线及状态变化。
5. 按顺序展开镜头块；每块有时间与职责、起幅/初态、动作触发、运镜路径与速度、物理响应、收幅及切点。
6. 结束状态与少量相关禁止项；持续视频保留合理微动态，不默认冻结。删除平台控件、批校验、模型版本等无关残留。

多镜块间的硬切独立一行写 `HARD CUT`，动作切可在邻接描述写 `Cut on action` 及动作相位。它们不冲突：前者说明切换形式，后者说明动作怎样接。只有连续单镜使用 `NO CUT`，按镜内节拍写，不出现独立切镜标记。连续镜头的景别变化靠可行的相机/主体运动；如需光学变焦，明确连续变化，不能无说明地跳换焦段。

## 示例：10 秒快速交锋的四镜设计

以下是原创时间安排示例，不是固定模板、来源实测或已验收视频。全局风格和真实资产绑定须按项目补齐。

```text
执行契约：10 秒，4 个依次播放的镜头，3 次硬切。
甲在左、乙在右，同侧轴线，两人右手持各自武器；环境声连续。

镜头一｜00:00–00:01.5｜1.5 秒｜发起
低机位脚步近景。乙后脚蹬地，身体向左送出，衣摆滞后。
在前脚将落地、攻击尚未完成时切出，不等他站稳再切。

HARD CUT

镜头二｜00:01.5–00:04.5｜3 秒｜交锋
同侧双人全景，完整保留头脚和武器路径，人物约占画高 75%。
Cut on action：接上镜落脚并完成突刺，甲侧身拨偏来剑；
乙顺势转髋横斩，甲迎挡。短距离侧移跟拍，在接触前切出。

HARD CUT

镜头三｜00:04.5–00:06.0｜1.5 秒｜接触与卸力
甲肩后近景，肩部仅占少量前景，焦点是双手与接触点。
承接横斩，双剑撞击滑开，手腕、肘和肩随冲击回弹。
甲转腕带偏来剑，动作尚在继续时切走，不重演横斩起手。

HARD CUT

镜头四｜00:06.0–00:10.0｜4 秒｜反击与新关系
回到同轴线斜侧双人全景，脚步可见。
承接卸力，甲踏步反击，乙侧撤回挡；用一次可读的攻守交换
改变两人的距离，摄影机同侧跟随。最后乙滑步退出攻击距离，
身体仍调整重心，发丝衣料有惯性；不额外停三秒摆造型。
```

## 提交前检查

- 一个生成片段是否被误当成一个摄影镜头？单镜选择是否有依据？
- 多镜稿是否有顺序镜号、起止时间、持续秒数和独立切镜标记？镜头数、切点数与正文是否一致？
- 时间是否加总正确，台词与动作是否能在区间内完成，实际模型参数是否支持？
- 每镜是否有独立信息职责，而不是同一动作换角度重复？
- 每个切点是否明确为什么此时切、切到哪里？动作阶段是否从上一镜继续而非重置？
- 机位、裁切和要求是否一致？要求看到落脚就不能写仅膝上取景；过肩须说谁的肩、看谁、遮挡多少。
- 轴线、运动方向、武器归属/手别、光向和声床是否保持？改变状态是否在画面中有因果？
- 是否残留与多镜冲突的“全段不切镜”，或与快动作冲突的无依据升格/定格？
- 实际输入、参考顺序、参数和输出是否留存在对应画布节点？修订稿不冒充旧视频真实输入。
