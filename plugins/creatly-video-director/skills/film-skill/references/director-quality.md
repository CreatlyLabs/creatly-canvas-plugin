# 导演质量控制

## 目标

把完整成片从「一次写完提示词并批量生成」调整为「导演设计、资产锁定、代表镜头试拍、确认后扩量」。本文件只提高创作质量，不改变 MCP Tool、节点关系、付费确认或生成状态契约。

完整成片默认采用质量优先模式。只有用户明确要求快速出样或接受较高返工风险时，才采用快速模式。完整流程还要读取 [制作圣经与镜头工作台](production-bible-and-shot-workbench.md)，把本文件的导演规则转换为固定常量、资产版本、镜头卡和生成记录。

## 区分事实与提案

前期设计中的每项结论都归入以下一种来源：

- **剧本事实**：剧本直接说明，后续不得随意修改；
- **强推断**：由多处剧情线索共同支持，记录简短依据；
- **导演提案**：剧本没有说明，但制作需要具体答案时，给出一套推荐及原因；
- **阻塞冲突**：不同答案会改变剧情、主体或付费范围时，只提出一个最关键的问题并等待确认。

不要把导演提案写成剧本事实。用户确认后，它才成为本项目后续节点共同使用的制作设定。非阻塞空白不让用户填写空表，直接给出一套保守且可执行的推荐。

## 建立项目制作设定

完整成片在主体和分镜设计前，先从定稿剧本形成以下内容：

1. 一句话故事、核心主题、主角目标、威胁和结尾变化；
2. 类型、现实程度和观众需要相信的世界边界；
3. 国家、地域、年代，以及建筑、服装、交通和通信限制；
4. 季节、天气、昼夜和剧情经历的时间；
5. 对白语言、口音、语速及人物阶层造成的表达差异；
6. 超自然、伤害、死亡、变异或其他世界规则；
7. 剧情经过的空间顺序和因果连接；
8. 主要人物小传、关系、外在目标、内在缺口和人物变化；
9. 换装、伤势、污渍、变异、道具转手和环境破坏的状态顺序；
10. 全片情绪曲线、呼吸区、最高点、结尾余韵和声音重点。

项目制作设定是 Script 的一部分。它必须能约束 Subject、Shot、Frame、Video 和声音设计，不能只作为聊天摘要。

### 文字情绪曲线

按真实剧情变化选择 8 到 14 个节点，短片较短时允许更少。每个节点记录剧情位置、事件短名、`0.0` 到 `10.0` 的情绪强度、升降原因和声音重点。至少保留一个有剧本依据的呼吸区，不机械把每个 Scene 当作节点，也不强制开头和结尾归零。

当前 Skill 不要求额外生成情绪曲线图片。没有正式画布节点或 Tool 承载该图片时，把文字曲线写入 Script，不能用聊天图片替代画布资产。

## 固定摄影与声音基准

导演包在逐镜头设计前还要固定：

- 一部主要影视参考及其具体借鉴维度；确有必要时增加一部只解决单一问题的补充参考；
- 实拍、动画或其他媒介，以及相互兼容的摄影机或胶片、镜头家族、画幅和帧率；
- 光源、曝光、高光、暗部、反差、肤色保护和禁用色；
- 颗粒、锐度、光晕、镜头缺陷和材质反射；
- 各 Scene 的环境声、同步动作声和非语言人声原则；
- 主要角色的音色、口音、语速和压力状态下的说话方式；
- 音乐的使用节点、主要乐器、频率重心、动态范围、留白和禁用声音。

影视参考必须立即转成可见或可听规则，不能只写片名。摄影介质之间不能自相矛盾。声音基准可以写入 Script 和 Shot，但只有实时 MCP 支持的 Audio 配置才能进入付费生成。

## 先形成导演包

写剧本和分镜前，先形成一份简短、可执行的导演包，并把最终结论写入 Script、Subject、Shot、Frame 和 Video 的对应可见字段。不要只把它留在聊天或内部推理中。

### 叙事意图

明确以下内容：

- 希望观众在开头、转折和结尾分别感受到什么；
- 全片最重要的一次信息揭示或情绪兑现；
- 哪个可见动作、道具或空间变化承担这次兑现；
- 每个 Shot 对故事的唯一作用。

无法说明镜头作用时，合并或删除该镜头。

### 视觉规则

视觉风格必须拆成可执行规则，至少包括：

- 媒介与成像方式，例如自然主义实拍、定格动画或厚涂二维动画；
- 时代、地域和生产设计；
- 主色、辅色、禁用色及其出现位置；
- 服装、建筑、道具的关键材质；
- 主光方向、软硬、色温和环境光关系；
- 常用焦段或透视倾向、机位高度和景深；
- 构图偏好、留白方向和主体在画面中的稳定位置；
- 对比度、颗粒、锐度等后期质感；
- 禁止出现的元素、镜头语言和视觉效果。

不要用「电影感」「高级感」「大片」「8K」「杰作」代替这些规则。这些词不能稳定控制画面。

### 角色身份锚点

每个重复出现的角色固定 5 到 8 个可见锚点，例如：

- 年龄段、身高和体型比例；
- 脸型、眉眼、鼻形或其他辨识特征；
- 肤色、发型、发色和发际线；
- 基础服装的颜色、剪裁、材质；
- 鞋履、眼镜、首饰或伤痕等固定特征。

同一角色的正视图、三视图和所有 Shot 使用完全相同的锚点措辞。临时情绪、湿衣、污渍或受伤状态另写为镜头状态，不修改基础身份。

### 场景空间图

每个重复场景固定：

- 出入口、窗户、主要家具和关键道具的位置；
- 前景、中景、背景的深度关系；
- 主光来源和阴影方向；
- 人物主要站位与移动路线；
- 对话视轴和允许的机位侧。

场景参考图、Shot 和 Frame 必须遵守同一空间图。不要只写氛围，不写空间关系。

重复场景还必须按 [场景设计与连续性](scene-design-and-continuity.md) 形成场景设计卡、参考视图覆盖计划和跨 Shot 连续性矩阵。场景资产数量由真实机位和状态变化决定，不为追求数量制造互相冲突的参考图。

### 连续性账本

逐 Shot 记录进入状态和离开状态：

```text
角色位置与朝向
手中道具与道具位置
服装、发型、污渍和伤痕状态
动作起点与结束点
时间、天气、光线和场景变化
上一镜如何接入，下一镜如何接出
```

下一镜的进入状态必须能从上一镜的离开状态得到。

最终 Frame 与 Video 提示词按 [场景设计与连续性](scene-design-and-continuity.md) 的来源顺序编译，确保全片视觉规则、角色基础身份、当前状态、场景锚点、Shot 设计和动作起点可追溯。

### 关键道具登记

只登记反复出现、参与关键动作、承担身份揭示，或具有文字、缺口、方向和左右结构的道具。为每件道具固定尺寸、材质、磨损、握持位置、当前持有人和状态变化，并在 Shot 与 Frame 中逐字复用关键锚点。

需要图片级一致性的叙事道具按 [主体创建](subjects.md) 的正式道具流程处理：当前 createSubject 使用 kind="scene" 的非角色分支和 subjectType="prop"，不等于把道具画成场景。分别验证主体库记录、画布应用节点与已归档素材；普通 element 容器及其子图不能代替正式主体证据。能力以实时 Schema 为准。

## 跨阶段一致性检查

进入付费生成前，不只检查单个节点，还要检查上游决定是否完整传到下游：

- 变更账本中已删除或合并的人物、场景和事件，不再被 Scene、Shot、主体或提示词引用；
- 每个主体都能指向实际使用它的 Scene 或 Shot，没有只创建但不使用的资产；
- 每个重复角色、场景和叙事道具都使用同一组基础锚点，状态变化有发生位置和先后顺序；
- 每个 Shot 中的角色、场景、道具和状态都来自当前有效剧本与生产清单；
- 每个关键转折都有前置证据，每个结尾兑现都能指回前面的目标、阻力或信息；
- 生成模型及参数来自本轮 `listGenerationModels`，节点生成配置已回读；
- 上游发生修改时，重新检查全部受影响的下游节点和引用，再进入生成。

发现失效引用、孤立资产或状态断裂时，先修正当前有效源头，再更新受影响节点。不要靠聊天记忆或在旧提示词后追加补丁维持一致性。

## 创作确认门禁

生成与状态查询按 [MCP 执行协议](mcp-execution.md) 及实时工具定义执行；每次新付费范围独立确认，回读真实媒体文件。

1. **故事方向确认**：主线、角色与关系、主要冲突、关键转折、结尾方向和改编取舍；确认前不写完整剧本。
2. **剧本与制作圣经确认**：完整剧本、角色身份与行为摘要、场景与关键道具、状态顺序、世界、摄影和声音常量；确认前不创建主体、不拆 Shot。
3. **资产清单确认**：需要创建、复用或分版本管理的角色、场景和商品主体，以及使用范围、依赖和验收标准；确认前不创建主体或参考 Frame。
4. **导演分镜与试拍确认**：全片 Scene 与 Shot 清单、每镜叙事目标、人物任务、时长、景别、主要动作、复杂度和转场；确认前不编写最终 Frame、Video 或 Audio 提示词，不创建 Scene 子树。确认后先完成代表镜头所在 Scene 的子树与试拍，不立即写入其余 Scene。

质量优先模式和快速模式都执行这些确认点。只有用户明确授权 Agent 自主决定全部创作内容并要求不中途确认，才能连续通过；该授权不代替付费确认。修改时从当前有效事实重新形成受影响内容，不在旧稿后追加相互冲突的补丁。

每个确认点都要结束当前回复并等待新的用户消息。展示方案、用户沉默、一般性的开始指令或 Agent 自己的质量判断都不构成确认。

## 用导演语言设计 Shot

每个 Shot 除了基础描述，还要明确：

| 字段            | 作用                                       |
| --------------- | ------------------------------------------ |
| `visualPurpose` | 本镜让观众看到、理解或感受到的唯一变化     |
| `characterTask` | 角色此刻要对谁完成什么，以及采用的动作策略 |
| `performance`   | 视线、呼吸、姿态、手部任务、停顿和反应     |
| `blocking`      | 人物和道具在空间中的站位、朝向与移动路线   |
| `composition`   | 主体位置、前中后景、视线空间和视觉焦点     |
| `cameraAngle`   | 平视、俯视、仰视、过肩等具体机位           |
| `lens`          | 焦段或透视倾向，以及选择它的原因           |
| `cameraMove`    | 有叙事动机的单一运镜；没有动机时保持静止   |
| `continuity`    | 从上一镜继承并交给下一镜的状态             |
| `transition`    | 动作接、视线接、声音接、硬切或其他明确接法 |

一个 Shot 默认只保留一个视觉焦点、一个主要动作链和一个相机意图。角色表演写「目标、阻力、策略和可见行为」，不用情绪形容词代替表演。多种运镜、多个动作高潮或多个信息揭示互相争夺时，应拆镜。

## 分阶段试拍

试拍前只创建代表镜头所在 Scene 的完整子树，并在写入后回读；不要求未来 Scene 已经创建。试拍通过后，剩余 Scene 按「完整子树原子写入、回读、生成、验收」逐个推进。试拍改变全片规则、资产版本或分镜结构时，先返回对应确认点，再继续创建后续 Scene。

### 第一阶段：锁定主体

1. 先生成角色正视图和固定场景参考图。
2. 等待成功终态，并回读文件证据。
3. 在可信项目页面检查角色辨识度、服装材质、色彩、空间结构和光线。
4. 不合格时只修改对应主体提示词，并以新的付费意图再次生成。
5. 正视图通过后再生成角色三视图，并检查三个角度的身份和服装一致性。

若 Agent 无法读取生成图片像素，必须明确请用户在项目页面完成视觉检查。文件存在只证明生成完成，不证明画面合格。

### 第二阶段：代表 Frame

从全片选择 1 到 3 个代表 Shot：

- 开场镜头，用于验证世界、风格和空间；
- 关系镜头，用于验证双人站位、视轴和身份一致性；
- 高潮镜头，用于验证最难的动作、情绪或画面设计。

全片不超过 3 个 Shot 时只选 1 个最难镜头。先生成这些 Shot 的 Frame，不同时生成其余 Frame。

检查：

- 角色身份和服装是否稳定；
- 场景结构、道具位置和光线是否符合空间图；
- 构图是否有明确焦点和足够深度；
- 首帧是否处于动作预备状态；
- 视觉规则是否真实落在画面中，而不是只存在于提示词中。

若失败，先判断问题属于主体资产、Shot 设计还是 Frame 提示词。修改最上游的真实原因，并只再次生成受影响的节点。

### 第三阶段：代表 Video

代表 Frame 通过后，再生成其直接下游 Video。检查：

- 人物身份、服装、道具和场景没有漂移；
- 动作按时间顺序完成，没有多余肢体或突然位移；
- 运镜只有一个清楚动机，速度与情绪一致；
- 开头承接首帧，结尾留出可剪辑的稳定状态；
- 镜头时长足够承载动作，没有在尾部仓促完成。

失败时只修改对应 Video 提示词；只有首帧本身错误时才回到 Frame。

### 第四阶段：逐 Scene 扩量

主体、代表 Frame 和代表 Video 都通过后，逐个编译、创建和生成其余 Scene。每个 Scene 完成后先检查身份、空间、动作、节奏和连续性，再进入下一 Scene；不提前完成全片最终提示词，也不把全片未验证镜头合成一个扩量批次。快速模式可以在主体锁定后扩大当前 Scene 内的生成批量，但不能合并多个尚未验收的 Scene，且必须在付费确认前说明返工风险。

每个失败镜头按 [制作圣经与镜头工作台](production-bible-and-shot-workbench.md) 记录版本、可观察问题和唯一主动修改项。同类失败约 3 次时重新判断资产、镜头设计和制作方法；长期试验仍不可用时，拆镜、减动作、改变机位或改用剪辑表达，不继续堆积同义约束。

生成与状态查询按 [MCP 执行协议](mcp-execution.md) 及实时工具定义执行；每次新付费范围独立确认，回读真实媒体文件。

## 质量诊断

| 问题             | 优先检查                 | 修正方向                               |
| ---------------- | ------------------------ | -------------------------------------- |
| 角色每镜不同     | 身份锚点、主体参考图     | 减少模糊形容词，固定同一组可见锚点     |
| 场景像随机背景   | 空间图、场景主体         | 固定出入口、家具、深度和光线位置       |
| 画面精致但无故事 | `visualPurpose`、动作链  | 每镜只保留一个叙事变化，删除装饰性镜头 |
| 构图平、没有重点 | 视觉焦点、前中后景       | 明确主体位置、遮挡、留白和景深         |
| 动作混乱         | 动作拍、时长             | 按时间拆成 1 到 3 个动作拍，必要时拆镜 |
| 运镜像随机漂移   | 运镜动机                 | 没有叙事原因时用静止机位               |
| 镜头无法顺剪     | 连续性账本、`transition` | 对齐进出状态，并为结尾保留稳定动作     |
| 风格忽冷忽暖     | 视觉规则                 | 固定色板、光源、材质和后期质感         |

不要用叠加更多画质形容词解决结构、身份、空间或动作问题。
