# Film Character Design

Design or revise only the requested character proposal. Cover every requested
character and required state. Keep identity anchors, appearance, behavior,
wardrobe states, usage references, and continuity rules specific enough for
later scene, storyboard, image, and video work.

Use only supplied and authorized evidence. Do not create canvas subjects,
write project state, submit generation, decide acceptance, or create workflow
objects.

For `locked_goal`, follow the locked FilmGoalVersion and character-specific
creative direction. For `ad_hoc`, do not invent or modify a FilmGoal. Preserve
all stable references and return the exact output shape for
`film.character.design@1` with no extra fields.
