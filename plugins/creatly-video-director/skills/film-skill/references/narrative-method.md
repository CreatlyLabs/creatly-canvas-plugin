# 叙事短片创作方法

以观众能读懂的事件、人物行动与镜头节奏完成一个短片。视觉媒介可以是写实、动画或混合；方法不绑定供应商、固定时长或某种生成路线。

## 从现有材料开始

已有定稿剧本时保留内容和逐字台词，先识别场景、人物任务、转折及结尾。用户只要求整理时，不顺便改写故事。只有梗概或想法时，先补全能支撑目标时长的事件和因果；欠缺会改变作品方向的信息才需要澄清。

从指定时长、明确节拍或已有素材判断规模。没有这些依据时给出带说明的估计，不默认把一个片段扩展成长片。只交付剧本、分镜或部分镜头也是成立的任务。

## 镜头是叙事单位

每个镜头说明它让观众看到的新信息、主要动作、进入状态、结束状态、声音及计划时长。先把对白、动作和反应留出合理空间，再按真实生成能力拆分；不把所有镜头固定成同一秒数，也不把“一个镜头”误认为“一次模型调用”。

同一动作需要连贯呈现时保留空间和状态依据；转场、时间跳跃、不同地点或蒙太奇不能仅因相邻播放而继承上一段视频。

## 选择能解决本镜问题的制作路线

| 情况                                      | 建议路线         | 必须说清的输入                           |
| ----------------------------------------- | ---------------- | ---------------------------------------- |
| 已有合适角色 / 场景素材，允许模型独立构图 | 参考素材生成视频 | 哪些素材约束身份或场景，哪些不决定构图   |
| 构图、文字布局、视线或首尾状态必须精确    | 分镜或首帧优先   | 经审阅的图片及其首帧 / 尾帧用途          |
| 简单、独立且不要求复用视觉身份的片段      | 文字生成视频     | 当前镜头完整的事件、画面和声音条件       |
| 用户指定延续或修改已有片段                | 视频参考 / 编辑  | 原片段的用途、应保留内容与允许修改的范围 |

优先遵从用户已经选定的路线。没有选定时推荐一个适合当前材料的方案，只在成本、控制力或产物确有差异时给第二个选项。只有未来确实要使用的参考才值得制作，不为完成清单而生成素材。

参考图、分镜图和首帧不是同义词。多格分镜图用于规划时，不把整张拼图默认当作一帧视频开场。

## 资产、声音与执行顺序

为跨镜复用的角色或场景明确身份和状态；状态变化会改变识别时使用不同引用。临时背景可以直接写进镜头。语音样本只提供音色依据，不能替换剧本里的对白；用户已确认的台词不得被模型任意缩写或润色。

按实际素材和验收条件形成工作图：分镜前先出本幕色卡图锁定色调，每个镜头的物料用组框住；独立镜头可并行，共用参考先准备，连续动作只有真正使用上游产物时才串行。选择分镜优先时，把图片审阅放在对应视频生成之前；选择直接参考路线时，不自动插入不需要的镜头首帧任务。

## 迭代与成片

读回真实结果后判断叙事是否成立、人物是否清楚、动作是否能接、声音是否符合要求。生成成功不代替这些判断。不可观察的内容保持待审阅，不能凭文件存在判定视觉合格。

只改有问题的镜头定义和实际受影响的下游。单纯调整播放顺序时，先判断是否仅需重组已有素材；不自动重新生成全片。最终按明确的剪辑顺序使用已采用媒体，交付作品定义、实际落点与未完成事项。
