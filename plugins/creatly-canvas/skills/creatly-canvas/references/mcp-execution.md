# 连接与执行协议

本分支连接 `https://test.yuanji.studio/api/agent/mcp/v2`，采用标准 Streamable HTTP MCP 与 OAuth。无需本地画布服务或保持浏览器画布打开。授权、凭据保存和续期由宿主管理；不读取用户凭据文件，不索取或复制密码、Cookie、访问令牌，不使用历史本地桥接替代授权。

首次连接按宿主提示完成网站授权。后续任务、重启和同一环境插件升级先复用原连接，不把每日 `/mcp`、重装或重复添加服务器当作启动步骤。账户和空间以 `listProjects` 等真实回执中的 authorizationContext 为准，令牌已经绑定时不重复询问。详细排障见 [账号连接与续期](../../../docs/oauth-connection.md)。

通过宿主实际提供的工具发现功能确认工具和完整 inputSchema。工具未注入、仅显示 unknown 或字段未展开，不足以认定远端没有能力；先读取定义，不靠试写节点猜参数，也不绕到旧 REST 或本地桥。确实缺少定义时保留待执行内容，说明具体缺口。

参数按实时 Schema 平铺传递，不套旧版 payload、不传本地 clientId。资源 ID 原样保留，各类 ID 不互换；版本类型、枚举、必填项和额外字段限制服从当前定义。

| 现象 | 处理 |
| --- | --- |
| 401 | 交给宿主正常续期或重新连接流程 |
| 403 | 检查目标资源和授权范围，不反复登录 |
| invalid_client / invalid_grant | 分别检查客户端注册/认证或刷新凭据，记录原始错误 |
| 429、5xx、stream timeout | 保留原回执并查询原操作，不清除授权、不自动重复写入 |
| invalid_arguments | 对照实时定义定位缺失、多传或类型不匹配的字段，原因明确后修正；同类错误修正仍失败时停止该写入 |
| 版本冲突 | 重读受影响节点，保留用户新修改，再决定本次操作 |

错误记录保留工具名、字段、code、message 和 traceId（如有），不展示令牌或签名 URL。未成功的写入不声称同步完成，其他独立且已授权的操作可以继续。
