# 运行时右侧画布预览

每次用户触发一次实际画布任务，在确定本次目标项目后，默认让目标画布出现在当前任务右侧的内置浏览器/网页预览中。只讨论方案、修改技能或尚未确定项目时，不随意打开一个项目；用户明确要求不打开或只要文字结果时按其要求执行。

## 检查、复用、重开

先通过当前宿主实际提供的面板/浏览器状态能力，查看当前任务的已打开标签及右侧栏是否展开，再决定操作。判断依据是当前界面状态，不是“已经打开过”的会话标记。

| 当前状态 | 本次行为 |
| --- | --- |
| 目标画布已在右侧打开 | 复用该标签，需要时切回它；不再新建、不强制刷新 |
| 标签还在，但右侧栏收起 | 展开右侧栏并显示原标签，不新建网页 |
| 没有目标画布，或用户已关闭原标签 | 用真实画布地址在右侧打开一次，保存宿主返回的标签标识供本轮复用 |
| 本次切换到另一个项目或环境 | 按新目标重新检查；已有对应标签就复用，否则打开该目标，保留用户其他页面 |

- 同一画布按实际环境域名及 workbench 项目路由识别。projectUrl 与其 nodeUrl、同项目不同 focusNode 的链接属于同一画布，不能因此重复开标签；真正导航仍保留服务端返回的完整地址。需要定位节点时在原标签内使用真实 nodeUrl。
- 不使用永久 opened=true 或过期标签 ID 跳过检查。用户关闭后，在下一次用户触发的画布任务中重新检查并打开；不要在关闭瞬间或同轮后台轮询中立刻抢回界面。新对话也不能假定旧预览仍存在。
- 本轮同项目的读取、写入、生成提交和状态轮询复用该预览，不每次 MCP 调用都打开页面，也不靠刷新页面来查询生成状态。网页预览不决定 MCP 任务能否继续运行。

## 地址与宿主能力

画布地址使用用户明确提供的目标链接，或当前工具回执中的 projectUrl/nodeUrl；不从明文 projectId 拼 workbench 路径，不为打开预览读取整份画布。没有地址时只读取取得目标项目链接所需的最小信息。

优先调用宿主实际开放的内置网页预览、标签复用和右侧显示能力，字段以该宿主实时工具定义为准。这些是客户端 UI 能力，不是 creatly MCP 工具；不编造 openCanvas、previewAssemble 等服务端接口，不用系统 open/浏览器命令冒充右侧预览，也不改全局链接打开偏好。

[WorkBuddy 右侧边栏说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Right-Sidebar)确认内置浏览器支持多标签和关闭标签，但不定义统一的 Agent 工具名；实际调用仍以当前客户端开放能力为准。仅有命令行、外部浏览器，或无法查询状态且没有明确可复用标签的打开能力时，说明右侧自动预览/去重的具体缺口，并交付[可点击画布链接](reading.md#给用户定位链接)，不声称已打开或已复用。

打开后以实际标签/页面结果确认成功。登录页、无权限或网络错误都不是画布已就绪；复用已有页面并如实说明状态，不通过反复新建网页或重置 MCP 授权处理。网站登录与 MCP 授权分别判断。
