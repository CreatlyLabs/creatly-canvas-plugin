# 媒体生成与状态

先读取用户指定节点、所需字段和真实参考，核对 listGenerationModels 当前可用模型及参数。使用 compact 定位后，仅对目标 modelIds 读 full。模型时长、引用格式、数量、画幅、分辨率、质量和音频能力以实时目录为准，不把文档映射当作底层供应商声明。

## 默认配置

用户明确指定优先；已有节点不因默认值变化被覆盖或重生成。

- 图片未指定时使用 Creatly Sigma 2.5 Sunburst、2K。记录的模型标识 gpt-image-2.5-sunburst、配置 ID image_gpt25_sunburst、function gpt25_sunburst、resolution 2k，提交前核对目录和写入字段；不传未开放的 function 或 quality:null。
- 视频未指定时使用 Seedance 2.5、480p、开启音频，显式配置 generationParams.resolution="480p"、generationParams.bgm=true。bgm 是音频总开关，包含对白和环境声音；用户仅要求无配乐时不要关闭全部音频。
- 默认组合不可用时说明具体缺口，不自动换付费模型、提升分辨率或增加数量。

## 提交与查询

1. 让节点实际配置、参考文件和顺序与本次请求一致；只读本次必要范围，素材要求由用户任务及当前模型能力决定。
2. calculateCredits 取得真实报价，核对用户已有授权的模型、范围、数量及总预算。没有授权的新增支出先在对话中确认；已覆盖的同一批不重复询问。实际预算上限通过 generateNodes.maxCredits 传入，不使用个人本地费用阈值。
3. 估价或配置写入可能改变版本，按实际返回更新所需观察摘要。保存幂等键、generationRef、nodeId、输入配置和任务回执；受理不等于完成。
4. 用 getGenerationStatus 查询原任务，再用 getNodes 的 media 核对真实文件。超时、网络错误或状态不明先查询，不换键重复提交。明确失败后的付费重试也须处于用户授权范围内。
5. 区分生成终态、目标节点挂载和内容验收。服务端通常自动挂载，不在每次完成后重复手动回写。成功但节点没有媒体时保留任务与文件证据，核对同步状态和版本；不靠付费重生成解决挂载异常。

交付真实任务状态和可用文件，并按[富文本节点链接](reading.md#给用户定位链接)提供本次结果。图片生成结果同样用可点击的图片名称链接到对应画布节点；可另附实际图片预览，不只贴图片文件地址或任务 ID。链接方便用户点击后居中查看和高亮定位；没有实际查看图像、视频或音频时不宣称内容通过验收。公开工具未提供剪辑或导出时，说明能力缺口，不假造 previewAssemble 等接口。
