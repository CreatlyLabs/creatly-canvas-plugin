# 人物横版四视图

用于已有角色参考图的定妆资产：一张横版白底图，左侧为正脸近景，右侧为全身正面、90°侧面和背面三视图。近景补足面部辨识细节，全身视图保留体型、服装和鞋履信息。

用户要求人物四视图时采用此布局；不是四幅全身照，不把一张合成板称为四张独立原图。真人或用户明确要求转真人时使用下面的摄影模板；其他风格保留指定媒介和材质。没有身份参考时先说明缺少输入，不声称已经锁定某个演员。

## 使用与提示词

先实际引用用户提供或已确认的同一角色图。多个参考图需明确身份、服装各自职责；不混用不同演员。画幅通常为横版 16:9，实际输出比例、分辨率和数量按用户要求及模型能力设置，不从“高解析”等提示词推断实际分辨率。体型和年龄遵循参考，“超模比例”仅用于原角色设定确实要求时。

> 根据参考图中已确认的同一角色，制作一张横版 16:9 真人定妆四视图，纯白无缝摄影棚背景。整张图只展示同一个人的四个视图：左侧约三分之一为一幅严格正面的精细头肩近景；右侧约三分之二为三幅完整全身照片，按正面 0°、侧面 90°、背面 180°依次排列。
>
> 左侧：人物完全正脸，视线平视镜头，头部不偏转、不俯仰，保持参考图的自然神态，不表演剧情动作。头顶、发际线、下巴、发型及头部配饰完整入镜。面部特征、五官间距、骨骼结构、年龄、肤色、眉眼、鼻唇轮廓和原有自然不对称均与参考图严格一致。真实呈现自然皮肤纹理、毛孔、与年龄相符的细纹、绒毛、眉睫、发丝及发际线碎发，保留皮肤受光后的细微起伏；不磨皮、不做美容修脸、不夸张锐化，也不额外增加皱纹、瑕疵或脏污。
>
> 右侧：三幅全身照始终是左侧近景中的同一个人，沿用参考图的头身比、肩宽、体型与身高观感。人物均为同一标准 A-pose，双臂自然向下外展约 20–30°，双脚平稳站立。三个视图保持相同人物缩放、相机高度、头顶与鞋底基线，完整展示头部、手、腿和鞋履，人物之间留出清楚间距。侧面严格为 90°，背面严格为 180°，不回头，不用镜像制造另一视角。
>
> 所有视图的服装设计、颜色、剪裁、布料层次、鞋子、发型与配饰一致，严格沿用参考图。布料、皮肤、头发、皮革和金属分别呈现真实物理材质与合理反光，不用统一塑料光泽覆盖。使用柔和、中性的摄影棚光线，肤色自然，白背景干净，服装固有色不漂移。画面清晰、透视自然，不加剧情场景、额外人物、装饰面板、文字或水印。

## 核对与画布操作

- 放大核对正脸近景的五官、眉睫、发际线和自然肤质；噪点、锐化白边、额外皱纹不能代替皮肤细节。
- 对照四个视图是否同一个人、服装配饰一致，侧面是否确为 90°、背面是否确为 180°，三幅全身是否同一缩放且头脚完整。未实际看图不宣称验收通过。
- 参考没有展示的背面属于补充设计，尽量延续可见结构，重要未知项标为待确认；不声称看不见的细节已经严格复刻。
- 写入使用[节点与素材](nodes-and-subjects.md)中的已有字段：默认按实时 Schema 写入普通图像节点；仅用户明确要求创建主体时使用角色资产计划，不虚构 fourView 参数。一张图不会自动成为四份主体素材；需要独立参考时使用实际得到并验收的原图或裁切。
- 近景用于面部细节，全身用于身体与服装；后续剧情不沿用白底和 A-pose。生成前核对[媒体生成与授权](generation.md)，模板本身不改变用户预算、模型偏好或授权数量，也不触发旧资产重生成。
